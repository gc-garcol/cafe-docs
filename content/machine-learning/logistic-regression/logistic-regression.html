Logistic Regression

A classifier that answers with a probability. It takes the same weighted sum as linear regression and bends it into an S-shaped curve between 0 and 1.

1. From a score to a probability

  
Linear regression gives a score $z = w x + b$ that can be any number. A probability must lie between 0 and 1. The sigmoid function squeezes any score into that range:

  
$$\sigma(z) = \frac{1}{1 + e^{-z}}, \qquad P(y = 1 \mid x) = \sigma(w x + b)$$

  
Big positive scores give probabilities near 1, big negative scores give probabilities near 0, and a score of exactly 0 gives $\tfrac{1}{2}$. Its slope is steepest in the middle, which is why the curve in the lab turns quickly near the boundary and flattens at the ends. A neat fact is that its derivative is $\sigma'(z) = \sigma(z)\,(1 - \sigma(z))$.

  
The model is still linear. It is the log-odds that depend linearly on $x$, not the probability.

  
$$\ln\frac{p}{1-p} = w x + b$$

  
The ratio $p/(1-p)$ is the odds. Add 1 to $x$ and the odds multiply by $e^{w}$. This makes the weights easy to interpret.






  
2. Making a decision

  
To turn a probability into a class, compare it with a threshold $t$. The usual choice is $t = 0.5$, which means "say 1 when it is more likely than not". For one feature this cuts the axis at a single point, the dashed vertical line in the lab:

  
$$\hat{y} = \begin{cases} 1 & p \ge t \\ 0 & p < t \end{cases} \qquad\Longrightarrow\qquad x^\ast = \frac{\ln\frac{t}{1-t} - b}{w}$$

  
With $t = 0.5$ the log term is zero and the boundary is simply $-b/w$. With more features the boundary becomes a straight line or plane, so logistic regression is a linear classifier, like the Perceptron. Move the threshold to trade one kind of mistake for the other. A low $t$ catches more true 1s but raises false alarms.






  
3. The loss

  
Squared error is a poor fit for probabilities. Instead, ask how likely the model thought the true labels were. For one example with label $y$ and predicted probability $p$, the log loss is:

  
$$\ell(p, y) = -\,y \ln p - (1 - y)\ln(1 - p)$$

  
If $y = 1$ the loss is $-\ln p$, which is zero when $p = 1$ and shoots up as $p$ approaches 0. A confident wrong answer is punished heavily. Averaging over all examples gives the training loss, which is the same as maximizing the likelihood of the data:

  
$$L(w, b) = \frac{1}{n}\sum_{i=1}^{n} \ell\big(\sigma(w x_i + b),\, y_i\big)$$

  
This loss is convex, so there is no bad local minimum to get stuck in.






  
4. Training with gradient descent

  
Unlike Linear Regression, there is no closed form answer, so we walk downhill. The gradient of the log loss has a pleasantly simple shape: for every example, take the error $p_i - y_i$ and weight it by the input.

  
$$\frac{\partial L}{\partial w} = \frac{1}{n}\sum_i (p_i - y_i)\,x_i, \qquad \frac{\partial L}{\partial b} = \frac{1}{n}\sum_i (p_i - y_i)$$

  
Each update is $w \leftarrow w - \eta \,\partial L/\partial w$, and likewise for $b$. Press Train 200 steps and watch the curve settle onto the data. The lab uses $\eta = 0.3$. If the two classes can be split perfectly, for example after you pull the groups apart, the best $w$ grows without bound because a steeper curve always lowers the loss. Real implementations add a penalty on the size of $w$, called regularization, to stop that.






  
5. Reading the errors

Precision is $\mathrm{TP}/(\mathrm{TP}+\mathrm{FP})$, how many alarms were real. Recall is $\mathrm{TP}/(\mathrm{TP}+\mathrm{FN})$, how many real cases were caught. The lab prints both.






  
6. The same thing in code

  
const sigmoid = z => 1 / (1 + Math.exp(-z));

function train(xs, ys, lr = 0.3, steps = 200) {
  let w = 0, b = 0;
  for (let s = 0; s < steps; s++) {
    let gw = 0, gb = 0;
    xs.forEach((x, i) => {
      const err = sigmoid(w * x + b) - ys[i];   // p - y
      gw += err * x;
      gb += err;
    });
    w -= lr * gw / xs.length;
    b -= lr * gb / xs.length;
  }
  return { w, b };
}






  
7. Where it fits

  

    
Strength
calibrated
The output is a probability you can rank, threshold, and explain with odds.

    
Use
baseline
Spam filters, credit risk, medical scores, and click prediction often start here.

    
Weakness
linear
The boundary is flat. For curved boundaries, add features or use a non-linear model.

  

  
With several classes, the sigmoid generalizes to the softmax, the last layer of most neural classifiers. The Bayesian view of the same output is in Bayes' Theorem. For the map of related methods, read Machine Learning Algorithm Groups.
