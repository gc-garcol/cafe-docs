Linear Regression

Draw the straight line that sits as close as possible to a cloud of points. It is the oldest and simplest way to predict a number from other numbers, and the starting point for most of machine learning.

1. The model

  
With one input $x$, the model is a line. The slope $w$ says how much the prediction changes when $x$ goes up by one. The intercept $b$ is the prediction when $x = 0$.

  
$$\hat{y} = w x + b$$

  
With many inputs, the line becomes a weighted sum, and the same idea holds. Stack a column of ones next to the inputs so that $b$ becomes just another weight:

  
$$\hat{y} = \mathbf{w}^\top \mathbf{x} = w_0 + w_1 x_1 + \cdots + w_d x_d$$

  
Linear means linear in the weights. The inputs can still be squared or logged before they go in.






  
2. The loss

  
To pick a line we need a score for how wrong it is. For each point the residual is $r_i = y_i - \hat{y}_i$. Squaring makes every error positive and punishes big misses more than small ones. Averaging gives the mean squared error:

  
$$\mathrm{MSE}(w, b) = \frac{1}{n}\sum_{i=1}^{n}\big(y_i - (w x_i + b)\big)^2$$

  
This is the total area of the squares in the lab, divided by $n$. The best line is the one with the smallest area. Because the loss is a smooth bowl in $w$ and $b$, there is exactly one lowest point.






  
3. The closed form answer

  
Set the slope of the bowl to zero in both directions and solve. For one input the result is short. Let $\bar{x}$ and $\bar{y}$ be the means.

  
$$w = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2}, \qquad b = \bar{y} - w\,\bar{x}$$

  
The numerator is the covariance of $x$ and $y$, and the denominator is the variance of $x$. So the slope is how much they move together, relative to how much $x$ moves on its own. The line always passes through the point $(\bar{x}, \bar{y})$, the center of the cloud.

  
For many inputs the same step is the normal equation. Here $X$ is the matrix of inputs with a column of ones, and $\mathbf{y}$ the vector of targets:

  
$$\hat{\mathbf{w}} = (X^\top X)^{-1} X^\top \mathbf{y}$$

  
Inverting $X^\top X$ costs about $O(d^3)$, so with very many features people train with Gradient Descent instead.






  
4. How good is the fit?

  
MSE depends on the units of $y$, so it is hard to judge alone. The coefficient of determination compares your line to the laziest model, which always predicts the mean:

  
$$R^2 = 1 - \frac{\sum_i (y_i - \hat{y}_i)^2}{\sum_i (y_i - \bar{y})^2}$$

  
A value of 1 means a perfect fit. A value of 0 means no better than the mean. It can even go negative for a line you placed badly, which you can see in the lab by dragging $w$ the wrong way.






  
5. The same thing in code

  
function fit(xs, ys) {
  const n = xs.length;
  const mx = xs.reduce((a, v) => a + v, 0) / n;
  const my = ys.reduce((a, v) => a + v, 0) / n;
  let sxy = 0, sxx = 0;
  for (let i = 0; i < n; i++) {
    sxy += (xs[i] - mx) * (ys[i] - my);
    sxx += (xs[i] - mx) ** 2;
  }
  const w = sxy / sxx;           // slope
  const b = my - w * mx;         // intercept
  return { w, b };
}






  
6. Where it works and where it breaks

  

    
Strength
simple
Fast, easy to explain, and every weight has a plain meaning. A strong baseline for any numeric target.

    
Weakness
outliers
Squared error lets one far point drag the whole line. Add a wild point in the lab and watch the fit swing.

    
Weakness
curves
A line cannot bend. Add features such as $x^2$ or switch to a non-linear model when the trend is curved.

  

  
When the target is a category instead of a number, use Logistic Regression. To see where linear regression sits among other methods, read Machine Learning Algorithm Groups. The related idea of fitting a curve exactly through every point is covered in Polynomial Interpolation.
