CAPM and Factor Models

CAPM says only market risk earns a premium, because everything else can be diversified away. Measured by beta, it predicts each asset's expected return. Factor models keep the regression and add more risk sources, and the leftover intercept is the alpha everyone hunts for.

Beta, alpha and noise

In Regression mode each dot is one month: the market's excess return against a stock's excess return. The slope is beta, the intercept alpha. In Security market line mode several stocks are placed by beta and average return.

How to use this simulator

  1. Set a true alpha of 0.5% a month, which is 6% a year, and keep 60 months. The estimate is usually not significant: the t-statistic is small.
  2. Raise the idiosyncratic volatility. The cloud spreads, $R^2$ falls, and beta gets less precise, while alpha gets even harder to see.
  3. Switch to Security market line. Assets with zero alpha scatter around the line by luck alone. Press New sample and watch "winners" change.
Estimates

1. The CAPM

If every investor holds the tangency portfolio from mean-variance theory, that portfolio is the market. An asset's expected excess return is then proportional to how much it moves with the market:

$$\mathbb E[R_i] - r_f = \beta_i\big(\mathbb E[R_m] - r_f\big), \qquad \beta_i = \frac{\operatorname{Cov}(R_i, R_m)}{\operatorname{Var}(R_m)}$$

Plotting expected return against beta gives a straight line, the security market line. Risk that is not correlated with the market earns nothing, because it disappears in a diversified portfolio.

2. Alpha and the regression

In data, run a time-series regression of excess returns on the market's excess return:

$$R_{i,t} - r_f = \alpha_i + \beta_i\,(R_{m,t} - r_f) + \varepsilon_{i,t}$$

CAPM says $\alpha_i = 0$. A positive, significant alpha means returns beyond what the risk taken explains. The variance splits into a systematic part $\beta^2\sigma_m^2$ and an idiosyncratic part $\sigma_\varepsilon^2$, and $R^2$ is the systematic share.

The standard error of $\hat\alpha$ is roughly $\sigma_\varepsilon/\sqrt{n}$. With 6% idiosyncratic volatility a month and 5 years of data, that is about 0.77% a month, so even a large true alpha of 0.5% is not detectable.

3. Factor models

CAPM's single factor explains returns poorly in practice. Factor models add more regressors, each a long-short portfolio that captures a known return pattern:

$$R_{i,t} - r_f = \alpha_i + \beta_{i}^{\text{MKT}}\,\text{MKT}_t + \beta_{i}^{\text{SMB}}\,\text{SMB}_t + \beta_{i}^{\text{HML}}\,\text{HML}_t + \dots + \varepsilon_{i,t}$$

Fama and French added size (small minus big) and value (high minus low book-to-market), later profitability and investment, and momentum is a common sixth. A strategy whose returns are explained by these betas has no alpha, only factor exposure you could buy more cheaply. Statistical factors from principal component analysis are another option.

import statsmodels.api as sm
X = sm.add_constant(factors[["MKT", "SMB", "HML"]])
fit = sm.OLS(stock_excess, X).fit(cov_type="HAC", cov_kwds={"maxlags": 6})
print(fit.params["const"], fit.tvalues["const"])        # alpha and its t-stat

Pitfalls

  • Betas move over time. Estimate on rolling windows and expect noise, especially for single stocks.
  • The empirical security market line is flatter than CAPM predicts: low-beta stocks have earned more than they should. That "betting against beta" effect is itself a factor.
  • Alpha depends on the benchmark. A fund that beats the market may have zero alpha against a factor model.
  • Use excess returns on both sides, and the same frequency and dates for the stock and the factors.
