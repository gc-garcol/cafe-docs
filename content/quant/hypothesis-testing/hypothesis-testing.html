Hypothesis Tests and p-values

A p-value answers one narrow question: if there were no effect, how often would data look at least this extreme? Used on one idea it is a useful filter. Used on a thousand backtests it will hand you dozens of false discoveries.

Is this edge real?

In One strategy mode you set a true daily edge and the test tries to detect it. In Many strategies mode every strategy has zero edge, and you see how many still look significant.

How to use this simulator

  1. In One strategy, set the edge to 0 and press New sample a few times. The p-value jumps around and is sometimes below 0.05 by chance.
  2. Give the strategy a small edge, such as 3 bp per day, and raise the number of days. See how many years it takes before the test reliably finds it.
  3. Switch to Many strategies. With 200 strategies and no edge, about 10 pass at the 5% level. Their best Sharpe ratio looks impressive.
  4. Turn on Bonferroni. The threshold drops to 0.05 / 200 and the false discoveries mostly disappear.
Test result

1. The recipe

  • Null hypothesis $H_0$: the thing you want to show is absent, here "the mean daily return is 0".
  • Test statistic: a number that is large when the data disagree with $H_0$.
  • p-value: the probability, assuming $H_0$ is true, of a statistic at least as extreme as the one observed.
  • Decision: reject $H_0$ if $p < \alpha$, with $\alpha$ fixed before looking, often 0.05.

For a mean the usual statistic is the t-statistic: the sample mean divided by its standard error. Under $H_0$ it follows a Student t distribution, which is close to $\mathcal N(0,1)$ for large $n$.

$$t = \frac{\bar r}{s/\sqrt{n}}, \qquad p = P\big(|T| \ge |t| \,\big|\, H_0\big)$$

Since the annualized Sharpe ratio is $\text{SR} = \sqrt{252}\,\bar r / s$, the t-statistic is simply $t = \text{SR}\sqrt{n/252} = \text{SR}\sqrt{\text{years}}$. A Sharpe of 1 needs about four years of data to reach $t = 2$.

2. What a p-value is not

A p-value is $P(\text{data} \mid H_0)$, not $P(H_0 \mid \text{data})$. Turning one into the other needs Bayes' theorem and a prior: if only 1 in 100 strategy ideas really works, most strategies that pass a 5% test are still false positives.

$H_0$ true (no edge)$H_0$ false (real edge)
reject $H_0$type I error, rate $\alpha$detection, rate = power
keep $H_0$correcttype II error, rate $1-\text{power}$

Power grows with the effect size and with $\sqrt n$. Small edges, which are the only kind most markets allow, need a lot of data to detect.

3. Multiple testing

Run $m$ independent tests where every null is true, and the chance that at least one passes is $1-(1-\alpha)^m$. With $m = 100$ and $\alpha = 0.05$ that is 99.4%. Trying many parameters, assets or signals and reporting the best one is exactly this.

$$\text{Bonferroni: reject only if } p < \frac{\alpha}{m}$$

Bonferroni is simple and strict. The Benjamini-Hochberg procedure controls the expected share of false discoveries instead, and is less harsh when you have many tests. In practice a rule of thumb from the literature is to ask for $t > 3$ for new factors, not $t > 2$.

from scipy import stats
t, p = stats.ttest_1samp(daily_returns, 0.0)      # two-sided test of mean = 0
from statsmodels.stats.multitest import multipletests
reject, p_adj, _, _ = multipletests(p_values, alpha=0.05, method="fdr_bh")

Pitfalls

  • Count every test you ran, including the ones you threw away. The number that matters is how many ideas you tried, not how many you report.
  • Returns are autocorrelated and fat-tailed, so the plain t-test overstates significance. Newey-West standard errors or a block bootstrap are safer.
  • Statistical significance is not economic significance. A tiny edge can be "significant" over 20 years and still vanish after costs.
  • Never pick $\alpha$, the sample period or the test after seeing the result.
