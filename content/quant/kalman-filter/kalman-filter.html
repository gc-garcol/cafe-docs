Kalman Filter

You want a value you cannot see directly, such as a fair price, a hedge ratio or a trend, and all you get are noisy readings of it. The Kalman filter combines a forecast with each new reading, trusting each in proportion to how precise it is, and keeps track of how uncertain the result is.

Tracking a hidden level

A hidden level $x_t$ moves as a random walk. You only see $y_t = x_t + $ noise. The filter estimates $x_t$ from the readings so far, without looking ahead. The band is its own $\pm 2$ standard deviation uncertainty.

How to use this simulator

  1. Leave the filter's assumed noise equal to the truth. The estimate follows the hidden level closely and the readout shows a lower error than the raw readings.
  2. Watch the bottom chart. The gain $K_t$ starts high, because the first guess is vague, then settles to a constant within a few steps.
  3. Raise the measurement noise $r$. The gain drops, so each reading moves the estimate less and the line gets smoother but lags more.
  4. Set the filter's assumed $q/r$ far from the truth. Too small and the estimate lags behind every move. Too large and it chases the noise. The error grows either way.

1. The state space model

A Kalman filter needs two equations. The state equation says how the hidden state moves. The observation equation says how readings relate to it. Both noises are Gaussian and independent:

$$x_t = F x_{t-1} + w_t,\ \ w_t \sim \mathcal N(0, Q) \qquad\qquad y_t = H x_t + v_t,\ \ v_t \sim \mathcal N(0, R)$$

The simulator uses the simplest case, the local level model: one state, $F = H = 1$, process variance $q$ and measurement variance $r$. Everything below works the same for vectors and matrices.

2. Predict, then update

Carry a mean $\hat x$ and a variance $P$ for the state. Each step has two halves. First, predict where the state is now, before seeing the new reading:

$$\hat x_{t\mid t-1} = F\hat x_{t-1}, \qquad P_{t\mid t-1} = F P_{t-1} F^\top + Q$$

Then correct the prediction with the reading. The innovation $y_t - H\hat x_{t\mid t-1}$ is the surprise, and the Kalman gain $K_t$ decides how much of it to believe:

$$K_t = \frac{P_{t\mid t-1}H^\top}{HP_{t\mid t-1}H^\top + R}, \qquad \hat x_t = \hat x_{t\mid t-1} + K_t\big(y_t - H\hat x_{t\mid t-1}\big), \qquad P_t = (1 - K_t H)P_{t\mid t-1}$$

In one dimension $K = P_{t\mid t-1}/(P_{t\mid t-1} + r)$. A precise reading (small $r$) gives $K$ near 1 and the estimate jumps to the reading. A vague one gives $K$ near 0 and the forecast wins. This is Bayes' theorem for Gaussians: the posterior mean is a precision-weighted average of the prior and the data.

3. Steady state and the moving average

For a fixed model, $P_t$ and $K_t$ converge quickly to constants that do not depend on the data. For the local level model, with signal-to-noise ratio $\lambda = q/r$,

$$K_\infty = \frac{-\lambda + \sqrt{\lambda^2 + 4\lambda}}{2}, \qquad \hat x_t = (1 - K_\infty)\,\hat x_{t-1} + K_\infty\, y_t$$

That second equation is an exponential moving average with weight $\alpha = K_\infty$. So an EMA is the optimal filter for a random walk seen through noise, and the Kalman filter tells you which $\alpha$ to use. The extras it adds are a principled warm-up, an uncertainty band, and a way to handle missing data or changing noise.

4. In quant work: a dynamic hedge ratio

In pairs trading the hedge ratio between two assets drifts. Treat it as the hidden state. The state is $\beta_t$, it follows a random walk, and each day's prices give a noisy reading through the regression $y_t = \beta_t x_t + v_t$, so $H_t = x_t$ changes every step:

import numpy as np
beta, P = 0.0, 1.0                    # vague prior
q, r = 1e-5, 1e-3                     # state drift and observation noise
betas = []
for xt, yt in zip(x, y):
    P = P + q                         # predict: beta follows a random walk
    S = xt * P * xt + r               # innovation variance
    K = P * xt / S                    # gain
    beta = beta + K * (yt - beta * xt)
    P = (1 - K * xt) * P
    betas.append(beta)

The same filter gives an innovation series $y_t - \beta_{t\mid t-1}x_t$ with variance $S_t$, and $(y_t - \beta_{t\mid t-1}x_t)/\sqrt{S_t}$ is a ready-made z-score for the spread. Other uses include estimating latent volatility, fitting term structure factor models, and fusing quotes from several venues into one fair price.

Pitfalls

  • The noise variances are the whole model. Fit them by maximum likelihood on the innovations, or the filter is just an EMA with an arbitrary weight.
  • Only the ratio $q/r$ sets the gain. Scaling both changes the uncertainty band but not the estimate, so a wrong band is easy to miss.
  • Using the smoother, which runs backward over the whole sample, gives estimates that depend on the future. Fine for analysis, look-ahead in a backtest.
  • The filter is optimal only for linear models with Gaussian noise. Fat-tailed jumps pull the estimate hard. Robust or particle filters help when that matters.
