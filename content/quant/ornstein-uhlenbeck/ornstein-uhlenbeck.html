Ornstein-Uhlenbeck Process

Brownian motion wanders off forever. Attach a spring that pulls it back toward a level, with a force proportional to the distance, and you get the Ornstein-Uhlenbeck process: the standard model for spreads, interest rates and anything else that mean-reverts.

How to use this simulator

  1. Raise $\theta$, the speed of reversion. Paths snap back to $\mu$ faster, the half-life in the readout falls, and the band stops widening sooner.
  2. Set $\theta$ near 0. The spring goes slack and the process looks like Brownian motion: the band keeps widening like $\sqrt t$.
  3. Change $\sigma$ with $\theta$ fixed. The band settles at $\sigma/\sqrt{2\theta}$, so more noise means a wider stationary spread, not a different mean.
  4. Read the "fitted from path" lines. An AR(1) regression on one highlighted path estimates $\theta$. With a short sample the estimate is noisy and usually too high.

1. The equation

The Ornstein-Uhlenbeck (OU) process solves the stochastic differential equation

$$dX_t = \theta(\mu - X_t)\,dt + \sigma\,dW_t, \qquad \theta > 0$$

The drift is a restoring force. Above $\mu$ it is negative, below $\mu$ it is positive, and it grows with the distance. $\theta$ sets how strong the pull is, $\mu$ where it pulls to, and $\sigma$ how hard the noise from the Brownian motion $W_t$ pushes back.

2. The solution

Apply Itô's lemma to $e^{\theta t}X_t$. The drift term cancels, and integrating gives an explicit solution:

$$X_t = \mu + (X_0 - \mu)e^{-\theta t} + \sigma\int_0^t e^{-\theta(t-s)}\,dW_s$$

The integral of a deterministic function against $dW$ is normal, so $X_t$ is normal with

$$\mathbb{E}[X_t] = \mu + (X_0-\mu)e^{-\theta t}, \qquad \operatorname{Var}(X_t) = \frac{\sigma^2}{2\theta}\big(1 - e^{-2\theta t}\big)$$

The gap to the mean decays exponentially. The variance starts at 0, grows like $\sigma^2 t$ for small $t$ exactly as Brownian motion does, then levels off.

3. Stationary distribution and half-life

As $t\to\infty$ the start is forgotten and $X_t$ settles into a fixed distribution:

$$X_\infty \sim \mathcal N\!\Big(\mu,\ \frac{\sigma^2}{2\theta}\Big), \qquad t_{1/2} = \frac{\ln 2}{\theta}$$

The half-life $t_{1/2}$ is the expected time for a deviation from $\mu$ to halve. It is the number traders quote for a spread, because it says how long a position has to be held for the trade to work. The autocorrelation at lag $\tau$ is $e^{-\theta\tau}$, so OU is stationary and has short memory, unlike Brownian motion.

4. Estimating it: OU is AR(1)

Sample the process every $\Delta t$. The exact solution over one step is a linear regression of $X_{t+\Delta t}$ on $X_t$:

$$X_{t+\Delta t} = a + bX_t + \varepsilon_t, \qquad b = e^{-\theta\Delta t},\quad a = \mu(1-b),\quad \operatorname{Var}(\varepsilon) = \frac{\sigma^2}{2\theta}\big(1-b^2\big)$$

So fit an AR(1) by least squares, then invert: $\hat\theta = -\ln \hat b/\Delta t$, $\hat\mu = \hat a/(1-\hat b)$ and $\hat\sigma = \operatorname{sd}(\hat\varepsilon)\sqrt{2\hat\theta/(1-\hat b^2)}$. This is also the exact maximum likelihood estimator for evenly spaced data.

import numpy as np
x0, x1 = x[:-1], x[1:]
b, a = np.polyfit(x0, x1, 1)                # x1 = a + b x0
theta = -np.log(b) / dt
mu = a / (1 - b)
resid = x1 - (a + b * x0)
sigma = resid.std(ddof=2) * np.sqrt(2 * theta / (1 - b**2))
half_life = np.log(2) / theta               # same units as dt
zscore = (x[-1] - mu) / (sigma / np.sqrt(2 * theta))   # distance in stationary sd

5. Where it shows up

  • Pairs and stat arb. The spread between two cointegrated assets is modeled as OU. Trade when the z-score $(X_t-\mu)/(\sigma/\sqrt{2\theta})$ is large and exit near the mean.
  • Interest rates. The Vasicek short-rate model is exactly an OU process for the rate, which gives closed-form bond prices.
  • Volatility. Log volatility is often modeled as OU, as in several stochastic volatility models, because volatility spikes and then decays.

Pitfalls

  • The estimate of $\theta$ is biased upward in short samples, so mean reversion looks faster and stronger than it is. You need a sample many half-lives long before $\hat\theta$ means much.
  • A random walk regressed on its own lag also gives $\hat b$ slightly below 1, which reads as weak mean reversion. Test for a unit root before trusting the fit.
  • OU is normal, so it can go negative. That is a problem for interest rates and prices, and is why models such as CIR or log-OU exist.
  • The long-run mean can shift. A spread that reverted for years can break when the relation behind it changes, so watch for structural breaks and use stop losses.
