Gradient Boosting

Boosting builds a strong model out of many weak ones. Each new tree is fitted to what the current model still gets wrong, and only a small step of it is added. It is the default for tabular data, including most of the features quants build.

How to use this simulator

  1. Press +1 round a few times from 0. Each tree is a few flat steps, and only a fraction $\eta$ of it is added.
  2. Drag the rounds slider up. Training error keeps falling. Validation error falls, bottoms out, then rises: the model starts fitting noise.
  3. Raise the learning rate. The minimum comes sooner and is usually worse. Small steps with more rounds generalize better.
  4. Set the tree depth to 1, stumps. Each tree is weak, but together they still trace the curve.

1. The algorithm

Start from a constant, the mean of the targets. Then repeat for $m = 1, \dots, M$:

  1. Compute the negative gradient of the loss at the current predictions. For squared loss these are just the residuals $r_i = y_i - F_{m-1}(x_i)$.
  2. Fit a small regression tree $h_m$ to the $r_i$.
  3. Add a shrunken copy of it: $F_m(x) = F_{m-1}(x) + \eta\,h_m(x)$.
$$F_M(x) = F_0 + \eta\sum_{m=1}^{M} h_m(x), \qquad h_m \approx -\frac{\partial L(y, F)}{\partial F}\Big|_{F = F_{m-1}}$$

It is gradient descent, but in the space of functions: each tree is a step in the direction that lowers the loss most. Other losses, such as log loss for classification or a Huber loss that is robust to outliers, only change step 1.

Random forests average deep trees grown independently to cut variance. Boosting adds shallow trees in sequence to cut bias. On noisy financial data, heavy regularization and early stopping matter more than the choice between them.

import lightgbm as lgb
model = lgb.LGBMRegressor(n_estimators=2000, learning_rate=0.02, num_leaves=15,
                          min_child_samples=200, subsample=0.7, subsample_freq=1,
                          colsample_bytree=0.7, reg_lambda=1.0)
model.fit(X_train, y_train, eval_set=[(X_val, y_val)],
          callbacks=[lgb.early_stopping(100)])          # validation must come after training in time

Pitfalls

  • Early stopping on a validation set that overlaps the training period in time leaks information. Use a later block.
  • Boosting chases outliers with squared loss. Clip targets or use a robust loss for returns.
  • Feature importance from gain is biased toward features with many split points. Permutation importance on validation data is more honest.
  • Trees cannot extrapolate. Outside the training range the prediction is flat.
