1. Where deep learning fits

  
Deep learning is a branch of machine learning, which is itself a branch of artificial intelligence. What makes it "deep" is the model: a neural network with many layers between the input and the output.

  
Classic machine learning often needs a person to design the features, such as edge counts for images or word counts for text. A deep network learns the features itself, straight from raw pixels, audio samples or tokens. Early layers pick up simple patterns, later layers combine them into richer ones.

  
Deep learning replaces hand-built features with features learned from data.






  
2. The neuron and the layer

  
A single artificial neuron takes a list of numbers, weighs each one, adds a bias, and passes the total through a nonlinear activation function $\sigma$:

  
$$a = \sigma\!\left(\mathbf{w}\cdot\mathbf{x} + b\right) = \sigma\!\left(\sum_{i} w_i x_i + b\right)$$

  
A layer is many neurons that read the same input. Stacking their weights into rows gives a matrix $W$, so a whole layer is one matrix product followed by $\sigma$ applied entry by entry. A network is a chain of such layers:

  
$$\mathbf{h}_1 = \sigma(W_1\mathbf{x} + \mathbf{b}_1), \quad \mathbf{h}_2 = \sigma(W_2\mathbf{h}_1 + \mathbf{b}_2), \quad \hat{y} = \sigma_{\text{out}}(W_3\mathbf{h}_2 + \mathbf{b}_3)$$

  
The weights $W_i$ and biases $\mathbf{b}_i$ are the parameters. The lab's readout counts them. Real models have millions to trillions.

  

    
ActivationFormulaTypical use

    
      
Sigmoid$\sigma(z) = \dfrac{1}{1 + e^{-z}}$Output probability for two classes

      
Tanh$\tanh z = \dfrac{e^{z} - e^{-z}}{e^{z} + e^{-z}}$Hidden layers in small networks, used in the lab

      
ReLU$\max(0, z)$Default for hidden layers in deep networks

      
Softmax$\dfrac{e^{z_i}}{\sum_j e^{z_j}}$Output probabilities for many classes

    
  

  
The nonlinearity is essential. Without it, stacking layers collapses: the product of two linear maps is just another linear map, so a hundred layers would be no stronger than one. In the lab, a single neuron (0 hidden layers) is a straight line, like logistic regression and the perceptron. The circle and XOR need the bend that a hidden layer adds.






  
3. How a network learns

  
Learning means finding parameters that make the output close to the right answer. Three pieces do it.

  
    
    
  • Loss. One number that says how wrong the network is. For two classes, the binary cross-entropy over $N$ examples is $L = -\frac{1}{N}\sum_{n}\big[y_n\log\hat{y}_n + (1-y_n)\log(1-\hat{y}_n)\big]$.
    • 
    
  • Backpropagation. The chain rule, applied layer by layer from the output back to the input, gives the gradient $\partial L/\partial \theta$ for every parameter in one backward pass.
    • 
    
  • Gradient descent. Nudge every parameter a small step against its gradient, with step size $\eta$, the learning rate.
    • 
  

  
$$\theta \leftarrow \theta - \eta\,\frac{\partial L}{\partial \theta} \qquad\text{with}\qquad \boldsymbol{\delta}^{(l)} = \big(W^{(l+1)}\big)^{\mathsf T}\boldsymbol{\delta}^{(l+1)} \odot \sigma'\!\big(\mathbf{z}^{(l)}\big)$$

  
The right-hand formula is the backward recursion. The error signal $\boldsymbol{\delta}$ at one layer comes from the layer after it, scaled by the derivative of the activation. For a sigmoid output with cross-entropy loss, the last signal is simply $\hat{y} - y$. This is what the page runs when you press Train: the full dataset is used for each step, and the loss falls as the boundary improves. See Gradient Descent for why the rate matters. A rate that is too large makes the loss bounce, and too small makes training crawl.






  
4. Why depth helps

  
The universal approximation theorem says that a network with one hidden layer, wide enough, can approximate any continuous function on a bounded region. So in principle one layer is enough. In practice, many real problems have structure that layers can reuse: edges build into shapes, shapes into parts, parts into objects. A deep network can express that hierarchy with far fewer neurons than a shallow, very wide one.

  
Try it in the lab with the Moons data. One hidden layer of width 2 gives a rough bend. Width 6 fits it well. Two layers of width 3 use the same six neurons, and after 1000 steps they reach a lower loss. Depth also has a cost: gradients can shrink or blow up as they travel through many layers, which is why choices like ReLU, careful initialization and normalization matter.






  
5. The main architectures

  
The plain stack of layers above is a multilayer perceptron. Other architectures build in assumptions about the data, so they need fewer parameters and less data.

6. What it takes in practice

  

    
IngredientWhy it matters

    
      
Lots of dataMillions of parameters need many examples to pin down. Small data leads to memorizing instead of learning.

      
ComputeTraining is huge amounts of matrix multiplication, so GPUs and similar chips are the norm.

      
Validation setTraining loss always falls. Only data the model has not seen shows whether it generalizes.

      
RegularizationWeight decay, dropout, data augmentation and early stopping fight overfitting.

      
OptimizerMini-batch SGD with momentum, or Adam, replaces plain full-batch descent at scale.

    
  

  
Deep learning is not always the right tool. For small tabular datasets, linear models and tree ensembles are often as accurate, faster to train and easier to explain. Reach for deep networks when the input is raw, high dimensional and there is plenty of data.






  
7. The same thing in code

  
const relu = z => Math.max(0, z);
const sigmoid = z => 1 / (1 + Math.exp(-z));

// one layer: out[i] = act( sum_j W[i][j] * x[j] + b[i] )
function layer(W, b, x, act) {
  return W.map((row, i) => act(row.reduce((s, w, j) => s + w * x[j], b[i])));
}

function forward(net, x) {
  const hidden = net.layers.slice(0, -1).reduce((h, L) => layer(L.W, L.b, h, relu), x);
  const last = net.layers[net.layers.length - 1];
  return layer(last.W, last.b, hidden, sigmoid);
}
