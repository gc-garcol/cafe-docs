Matrix Rank

The number of independent rows or columns in a matrix. Rank says how much information a matrix keeps, how many equations are really different, and how many solutions a system has.

Try it first

Edit the $3 \times 3$ matrix, or use a preset. Row reduction clears each column with a pivot where it can. The number of pivots is the rank. Blue columns hold a pivot, so they are independent. Orange columns are combinations of the earlier ones.

1. What rank measures

  
The columns of a matrix are vectors. Some of them may be redundant, because they can be built from the others. The rank is the number of independent columns, which is the dimension of the space they span. That space is the column space, or the image of the matrix when you see it as a linear map.

  
A surprising fact: the number of independent rows is the same. So $\operatorname{rank} A = \operatorname{rank} A^{\mathsf T}$, and for an $m \times n$ matrix the rank is at most $\min(m, n)$.

  
Rank is how many directions the matrix really uses.






  
2. Finding it by row reduction

  
Gaussian elimination only uses three row operations: swap two rows, scale a row, and add a multiple of one row to another. None of them changes the rank. Reduce until each pivot is the only nonzero entry in its column. The count of pivots is the rank.

  
Take the default matrix. Row 2 is twice row 1, so one row becomes zero and only two pivots remain. The orange column, $(3,6,1)^{\mathsf T}$, is just the first column plus the second.

  
$$\begin{bmatrix} 1 & 2 & 3 \\ 2 & 4 & 6 \\ 1 & 0 & 1 \end{bmatrix} \longrightarrow \begin{bmatrix} 1 & 0 & 1 \\ 0 & 1 & 1 \\ 0 & 0 & 0 \end{bmatrix} \quad \Rightarrow \quad \operatorname{rank} = 2$$

  
Floating point makes "exactly zero" fuzzy, so software uses the singular values instead and counts the ones above a tolerance.






  
3. Rank plus nullity

  
The null space is the set of vectors $\mathbf{x}$ with $A\mathbf{x} = \mathbf{0}$. Each column without a pivot gives one free direction in it. Its dimension is the nullity.

  
$$\operatorname{rank} A + \operatorname{nullity} A = n \quad (\text{the number of columns})$$

  
This is the rank-nullity theorem. The directions the matrix keeps and the directions it crushes to zero use up all $n$ dimensions of the input. The lab lists a basis of the null space under the readout.






  
4. Rank and solutions

  
For the system $A\mathbf{x} = \mathbf{b}$, compare the rank of $A$ with the rank of the augmented matrix $[A \mid \mathbf{b}]$.

  

    
ConditionSolutions

    
      
$\operatorname{rank} A < \operatorname{rank}[A \mid \mathbf{b}]$None. The equations contradict each other.

      
$\operatorname{rank} A = \operatorname{rank}[A \mid \mathbf{b}] = n$Exactly one.

      
$\operatorname{rank} A = \operatorname{rank}[A \mid \mathbf{b}] < n$Infinitely many, with $n - \operatorname{rank}$ free parameters.

    
  

  
A square matrix has full rank exactly when its determinant is not zero.






  
5. Useful facts

  
    
    
  • $\operatorname{rank}(AB) \le \min(\operatorname{rank} A, \operatorname{rank} B)$. Multiplying never adds information.
    • 
    
  • A rank 1 matrix is an outer product $\mathbf{u}\mathbf{v}^{\mathsf T}$, one column times one row.
    • 
    
  • Low rank means compressible. Keeping the top $k$ singular values gives the best rank $k$ approximation of an image.
    • 
    
  • Adding a row or column cannot lower the rank.
    • 
  






  
6. The same thing in code

  
function rank(M, eps = 1e-9) {
  const A = M.map(r => r.slice());
  let r = 0;
  for (let c = 0; c < A[0].length && r < A.length; c++) {
    let p = r;
    for (let i = r + 1; i < A.length; i++) if (Math.abs(A[i][c]) > Math.abs(A[p][c])) p = i;
    if (Math.abs(A[p][c]) < eps) continue;
    [A[r], A[p]] = [A[p], A[r]];
    for (let i = r + 1; i < A.length; i++) {
      const m = A[i][c] / A[r][c];
      A[i] = A[i].map((x, k) => x - m * A[r][k]);
    }
    r++;
  }
  return r;
}






  
7. Where it shows up

  

    
Data
compression
Low rank approximations store a big matrix with far fewer numbers.

    
Statistics
redundancy
Rank deficient data means some features are copies of others, and regression breaks.

    
Control
reachability
A system is controllable when a certain matrix has full rank.
