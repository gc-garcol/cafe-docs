Linear Maps

A function between vector spaces that keeps lines straight and the origin fixed. Adding then mapping gives the same answer as mapping then adding, and the same goes for scaling.

For a linear map, $T(\mathbf{u} + \mathbf{v})$ lands exactly on the ring at $T(\mathbf{u}) + T(\mathbf{v})$, and the grid stays a grid. The last two presets are not linear: the ring misses.

1. The definition

  
A function $T: V \to W$ between two vector spaces is linear if it passes two tests for all vectors and numbers:

  
$$T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v}) \qquad\qquad T(c\,\mathbf{u}) = c\,T(\mathbf{u})$$

  
They can be merged into one: $T(a\mathbf{u} + b\mathbf{v}) = aT(\mathbf{u}) + bT(\mathbf{v})$. A consequence is that $T(\mathbf{0}) = \mathbf{0}$, so any map that moves the origin, like the shift, cannot be linear. In the lab the readout shows the gap for each test. For the square map, $T(\mathbf{u}+\mathbf{v})$ and $T(\mathbf{u})+T(\mathbf{v})$ differ by the cross term $2u_1 v_1$.

  
Linear means: know the map on a basis and you know it everywhere.

3. Kernel and image

  
Two subspaces describe what a linear map does.

  
    
    
  • The kernel, $\ker T = \{\mathbf{v} : T(\mathbf{v}) = \mathbf{0}\}$, holds everything that gets crushed to zero. The projection above has the $y$-axis as its kernel.
    • 
    
  • The image, $\operatorname{im} T = \{T(\mathbf{v})\}$, holds every possible output. It is the column space of the matrix.
    • 
  

  
Their dimensions always balance:

  
$$\dim V = \dim \ker T + \dim \operatorname{im} T$$

  
This is the rank-nullity theorem from Matrix Rank, seen from the map side. The map is injective (one to one) exactly when the kernel is $\{\mathbf{0}\}$. It is surjective (onto) exactly when the image is all of $W$. A map that is both is an isomorphism. It has an inverse, and the spaces are the same up to renaming.






  
4. Composition is multiplication

  
Applying $S$ and then $T$ is another linear map, written $T \circ S$. For maps on $\mathbb{R}^n$ that is exactly matrix multiplication, which is why the product order feels backwards: the matrix nearest the vector acts first.

  
$$(T \circ S)(\mathbf{x}) = T(S(\mathbf{x})) \;\Longleftrightarrow\; A_T A_S\,\mathbf{x}$$

  
Every linear map from $\mathbb{R}^n$ to $\mathbb{R}^m$ is multiplication by one specific $m \times n$ matrix, built from where the basis vectors go. See the matrix of a linear map.






  
5. Where it shows up

  

    
Graphics
transforms
Scale, rotate and shear are linear. Translation needs an extra coordinate to fit in.

    
Calculus
$d/dx$
Derivatives and integrals are linear operators on spaces of functions.

    
Signals
filters
A linear time invariant system maps input signals to output signals linearly.
