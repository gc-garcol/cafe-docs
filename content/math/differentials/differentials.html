Differentials

The derivative is a slope. The differential is what that slope predicts: nudge $x$ by $dx$, and the tangent line says $y$ moves by $dy = f'(x)\,dx$. It is the linear part of the true change, and the leftover shrinks much faster than the nudge.

Try it first

Pick a point $a$ and a step $dx$. The orange bar is $dy$, the rise along the tangent. The blue bar is $\Delta y$, the real rise along the curve. The gap between them is the error. Shrink $dx$ and watch the gap vanish faster than $dx$ itself: the ratio $\text{error}/dx$ goes to zero, while $\text{error}/dx^2$ settles on $\tfrac{1}{2}f''(a)$.

1. Two kinds of change

Take $y = f(x)$ and move $x$ from $a$ to $a + \Delta x$. There are two ways to say how much $y$ moved.

True change
Δy

$f(a + \Delta x) - f(a)$. Exact, but you need to evaluate $f$ twice and subtract.

Differential
dy

$f'(a)\,dx$. The change if the curve were its tangent line. Linear in $dx$, so it is easy to compute and to combine.

Leftover
Δy − dy

Shrinks faster than $dx$. For a smooth $f$ it is about $\tfrac{1}{2}f''(a)\,dx^2$.

For the independent variable we simply set $dx = \Delta x$. The two notions only split apart for the dependent variable $y$.

A worked example

For $y = x^2$ at $a = 3$ with $dx = 0.1$:

$$\begin{aligned} dy &= 2a\,dx = 2 \cdot 3 \cdot 0.1 = 0.6 \\ \Delta y &= 3.1^2 - 3^2 = 9.61 - 9 = 0.61 \\ \Delta y - dy &= 0.01 = dx^2 \end{aligned}$$

Here the error is exactly $dx^2$, because $(a + dx)^2 = a^2 + 2a\,dx + dx^2$. Halve $dx$ and $dy$ halves, but the error drops to a quarter. That is the whole point.

2. The definition

A function is differentiable at $a$ when its change splits into a linear part plus something negligible compared to $dx$:

$$\Delta y = f'(a)\,dx + \varepsilon(dx)\,dx, \qquad \varepsilon(dx) \to 0 \text{ as } dx \to 0$$

The linear part is the differential:

$$dy = f'(x)\,dx$$

Dividing by $dx$ gives back $\frac{dy}{dx} = f'(x)$. So Leibniz's notation is not just a symbol: it really is a ratio of two differentials. This is also the cleanest way to read the derivative. $f'(a)$ is the number that turns a small input change into the best linear guess of the output change.

The derivative is the rate. The differential is the rate times the step.

3. Rules for differentials

Every derivative rule has a differential twin. Multiply both sides by $dx$ and the rules become statements about small changes, with no reference to which variable is independent.

RuleDifferential
Constant$d(c) = 0$
Sum, constant multiple$d(c\,u + v) = c\,du + dv$
Product$d(uv) = u\,dv + v\,du$
Quotient$d\!\left(\frac{u}{v}\right) = \frac{v\,du - u\,dv}{v^2}$
Composition$d\,f(u) = f'(u)\,du$
Examples$d(x^n) = n x^{n-1} dx$, $d(\sin u) = \cos u\,du$, $d(\ln u) = \frac{du}{u}$

Invariance of form

The formula $dy = f'(u)\,du$ holds whether $u$ is the independent variable or itself a function $u = g(x)$. In the second case $du = g'(x)\,dx$, and substituting gives $dy = f'(g(x))\,g'(x)\,dx$, which is the chain rule. You can differentiate layer by layer and never decide in advance which variable is "the" variable.

  1. $y = \sin(x^2)$. Let $u = x^2$, so $du = 2x\,dx$ and $dy = \cos u\,du = 2x\cos(x^2)\,dx$.
  2. $y = \ln(1 + e^x)$. Then $dy = \frac{d(1 + e^x)}{1 + e^x} = \frac{e^x}{1 + e^x}\,dx$.
  3. $y = x^2 e^{3x}$. Product: $dy = e^{3x}\,d(x^2) + x^2\,d(e^{3x}) = (2x + 3x^2)\,e^{3x}\,dx$.

4. Estimating values

When $f(a)$ and $f'(a)$ are easy but $f(a + dx)$ is not, use $f(a + dx) \approx f(a) + dy$.

  1. $\sqrt[3]{8.3}$: with $f(x) = x^{1/3}$, $a = 8$, $f'(8) = \frac{1}{3 \cdot 8^{2/3}} = \frac{1}{12}$ and $dx = 0.3$, so $\sqrt[3]{8.3} \approx 2 + \frac{0.3}{12} = 2.025$. True value: $2.02469\ldots$
  2. $\sin 31^\circ$: with $a = 30^\circ = \frac{\pi}{6}$ and $dx = 1^\circ = \frac{\pi}{180} \approx 0.017453$ (angles must be in radians), $\sin 31^\circ \approx \frac{1}{2} + \frac{\sqrt{3}}{2} \cdot 0.017453 \approx 0.515115$. True value: $0.515038\ldots$
  3. $(1.002)^{50}$: with $f(x) = x^{50}$ at $a = 1$, $dy = 50 \cdot 0.002 = 0.1$, so the estimate is $1.1$. True value: $1.10506\ldots$ The gap is larger because $f''(1) = 2450$ is large.

The last case is a warning. The estimate is only as good as the curve is straight over the step, and the second derivative measures how far from straight it is.

5. Error propagation

A measurement $x$ comes with an uncertainty $dx$. Any quantity computed from it inherits an uncertainty $dy = f'(x)\,dx$. This is how lab sheets and engineering tolerances are worked out.

A worked problem

The radius of a ball is measured as $r = 10$ cm, give or take $0.05$ cm. How uncertain is its volume?

  1. $V = \frac{4}{3}\pi r^3 \approx 4188.8\ \text{cm}^3$.
  2. $dV = 4\pi r^2\,dr = 4\pi \cdot 100 \cdot 0.05 = 20\pi \approx 62.8\ \text{cm}^3$.
  3. Relative error: $\frac{dV}{V} = 3\,\frac{dr}{r} = 3 \cdot 0.5\% = 1.5\%$.

The relative form is the useful habit. Take $d \ln$ of a power law and exponents become multipliers:

$$y = C\,x^n \quad\Longrightarrow\quad \frac{dy}{y} = n\,\frac{dx}{x}$$

A cube's volume carries three times the relative error of its side. A square root halves it.

6. Several variables: the total differential

When $z = f(x, y)$ depends on two inputs, each contributes its own linear piece. The partial derivatives are the rates, and the total differential adds them up:

$$dz = \frac{\partial f}{\partial x}\,dx + \frac{\partial f}{\partial y}\,dy$$

Geometrically, $dz$ is the rise along the tangent plane, the two-variable version of the tangent line in Fig 1.

A worked problem

A can has radius $r = 3$ cm and height $h = 10$ cm, with errors $dr = 0.01$ and $dh = 0.02$. Its volume is $V = \pi r^2 h = 90\pi \approx 282.74\ \text{cm}^3$.

$$dV = 2\pi r h\,dr + \pi r^2\,dh = 0.6\pi + 0.18\pi = 0.78\pi \approx 2.45\ \text{cm}^3$$

That is about $0.87\%$, matching the relative rule $\frac{dV}{V} = 2\frac{dr}{r} + \frac{dh}{h}$. The radius error counts twice, so a better ruler for $r$ pays off more than one for $h$.

Implicit curves

Differentials also handle equations that are not solved for $y$. On the circle $x^2 + y^2 = 25$, take $d$ of both sides: $2x\,dx + 2y\,dy = 0$, so $\frac{dy}{dx} = -\frac{x}{y}$. At $(3, 4)$ the slope is $-\frac{3}{4}$.

7. Differentials inside integrals

The $dx$ in $\int f(x)\,dx$ is the same object. It is the width of a thin slice, and it is why substitution works: rename the inside, and rename its differential with it.

$$\int 2x\cos(x^2)\,dx \;\xrightarrow{\;u = x^2,\; du = 2x\,dx\;}\; \int \cos u\,du = \sin(x^2) + C$$

Differential equations use the same notation. $\frac{dy}{dx} = k y$ becomes $\frac{dy}{y} = k\,dx$, and integrating both sides gives $\ln|y| = kx + C$, so $y = A e^{kx}$.

8. Higher-order differentials

Apply $d$ again, holding the step $dx$ fixed. For an independent $x$ that gives $d^2 y = f''(x)\,dx^2$, which is where the notation $\frac{d^2 y}{dx^2}$ comes from. It is also the size of the leftover in the lab: $\Delta y - dy \approx \tfrac{1}{2}\,d^2 y$.

One catch: unlike $dy$, the second differential is not invariant. If $x = g(t)$, then $dx$ itself changes and $d^2 y = f''(x)\,dx^2 + f'(x)\,d^2 x$. The extra term is why second-order formulas need care when you change variables.

9. The same thing in code

Comparing $dy$ with $\Delta y$ numerically shows the orders of the error directly. Error propagation is one line per input.

const f  = x => x * x;
const df = x => 2 * x;

for (const dx of [0.1, 0.01, 0.001]) {
  const dy = df(3) * dx;            // linear prediction
  const Dy = f(3 + dx) - f(3);      // true change
  console.log(dx, dy, Dy, Dy - dy);
}
// 0.1    0.6     0.61       ≈ 1e-2
// 0.01   0.06    0.0601     ≈ 1e-4
// 0.001  0.006   0.006001   ≈ 1e-6   (error = dx², exactly, up to rounding)

// Worst-case error of V = πr²h from the total differential
const dV = (r, h, dr, dh) => Math.abs(2 * Math.PI * r * h * dr) + Math.abs(Math.PI * r * r * dh);
dV(3, 10, 0.01, 0.02);  // 2.4504

When the input errors are independent and random rather than worst case, statisticians add the pieces in quadrature instead: $\sigma_z^2 \approx (f_x\,\sigma_x)^2 + (f_y\,\sigma_y)^2$. Both come from the same total differential.

10. Common mistakes

  • Treating $dy$ as the exact change. It is the tangent-line change; $\Delta y$ is exact.
  • Using degrees for $dx$ in trig estimates. $d(\sin x) = \cos x\,dx$ only holds with $x$ in radians.
  • Dropping a variable in the total differential. Every input that can move needs its own term.
  • Letting errors cancel. For worst-case bounds, add the absolute values of each term.
  • Trusting the estimate on a large step or where $f''$ is big. Check the size of $\tfrac{1}{2}f''(a)\,dx^2$ first.

11. Next

The differential keeps only the first-order part of a change. Keeping the $dx^2$, $dx^3$ and higher terms too gives the Taylor series. Adding infinitely many differentials $f(x)\,dx$ back up gives the integral.
