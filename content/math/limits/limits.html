Limits

What value does a function head toward as its input gets close to a point? A limit answers that, even when the function is undefined at the point itself. It is the one idea that derivatives, integrals and series are all built on.

1. The idea

Take $f(x) = \frac{x^2 - 1}{x - 1}$. At $x = 1$ it is $\frac{0}{0}$, so $f(1)$ does not exist. For every other $x$ the fraction factors as $\frac{(x-1)(x+1)}{x-1} = x + 1$.

x (from the left)f(x)x (from the right)f(x)
$0.9$$1.9$$1.1$$2.1$
$0.99$$1.99$$1.01$$2.01$
$0.999$$1.999$$1.001$$2.001$

Both columns crowd toward $2$. The function never has to reach $2$, and it does not even have to be defined at $1$. We write:

$$\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = 2$$

Read it as "the limit of $f(x)$ as $x$ approaches $1$ is $2$". Informally: you can make $f(x)$ as close to $2$ as you like by taking $x$ close enough to $1$, but not equal to it.

A limit is about the neighborhood of a point, not the point itself.

The "Moved point" example in the lab makes this concrete. It is $x^2$ everywhere except that $f(1)$ has been redefined to $3$. The limit at $1$ is still $1$, because no amount of fiddling with the single value $f(1)$ changes what nearby values do.

2. One-sided limits

You can approach $a$ from below ($x \to a^-$) or from above ($x \to a^+$). The two-sided limit exists only when both one-sided limits exist and are equal.

$$\lim_{x \to a} f(x) = L \iff \lim_{x \to a^-} f(x) = L \text{ and } \lim_{x \to a^+} f(x) = L$$

In the Jump example, $\frac{|x|}{x}$ equals $-1$ on the left of $0$ and $+1$ on the right. Each side has a limit, but they disagree, so $\lim_{x \to 0} \frac{|x|}{x}$ does not exist.

Fig 2 · Both sides settle, but on different values.

One-sided limits are also the natural tool at the edge of a domain. $\sqrt{x}$ is only defined for $x \ge 0$, so at $0$ only $\lim_{x \to 0^+} \sqrt{x} = 0$ makes sense.

3. Three ways a limit fails

The lab has one example of each. They are worth telling apart, because each needs a different fix or a different answer.

Jump
sides disagree

Both one-sided limits exist but differ, as with $\frac{|x|}{x}$ at $0$. Floor, sign and step functions do this.

Blow-up
unbounded

$\frac{1}{x^2}$ grows past every bound near $0$. We write $\lim = +\infty$, which is a precise way to say the limit does not exist as a number.

Oscillation
no settling

$\sin\frac{1}{x}$ swings between $-1$ and $1$ infinitely often near $0$. No single value attracts it from either side.

A quick test for oscillation: find two sequences that both approach $a$ but give different outputs. For $\sin\frac{1}{x}$, take $x_n = \frac{1}{2\pi n}$ (outputs all $0$) and $x_n = \frac{1}{2\pi n + \pi/2}$ (outputs all $1$). Two different targets, so no limit.

4. The precise definition

"Gets close" needs a measuring stick. Think of it as a game. A challenger picks a tolerance $\varepsilon \gt 0$ around $L$. You must answer with a window $\delta \gt 0$ around $a$ such that every $x$ in the window (except $a$ itself) lands inside the tolerance. If you can always answer, however small $\varepsilon$ gets, the limit is $L$.

$$\lim_{x \to a} f(x) = L \iff \forall \varepsilon \gt 0\ \exists \delta \gt 0 : 0 \lt |x - a| \lt \delta \Rightarrow |f(x) - L| \lt \varepsilon$$

Fig 3 · Inside the blue window the curve never leaves the orange band.

A worked proof

Claim: $\lim_{x \to 2} (3x + 1) = 7$. Work backwards from what we need.

  1. We want $|f(x) - 7| \lt \varepsilon$, that is $|3x + 1 - 7| = |3x - 6| = 3|x - 2| \lt \varepsilon$.
  2. That holds exactly when $|x - 2| \lt \frac{\varepsilon}{3}$.
  3. So answer every challenge with $\delta = \frac{\varepsilon}{3}$. Then $0 \lt |x - 2| \lt \delta$ gives $|f(x) - 7| = 3|x-2| \lt 3\delta = \varepsilon$. Done.

For a line, $\delta$ is a fixed fraction of $\varepsilon$. For curves, $\delta$ usually depends on $\varepsilon$ in a more complicated way, which is what the lab computes numerically. Turn on the game with "Jump" and "Both" selected: once $\varepsilon \lt 1$, no window works, because points on the two sides are $2$ apart.

5. Limit laws

Proving every limit from $\varepsilon$ and $\delta$ would be slow. Instead, prove a few rules once. If $\lim f = L$ and $\lim g = M$ (both at the same point $a$, both finite), then:

RuleStatement
Sum$\lim (f + g) = L + M$
Constant multiple$\lim (c f) = c L$
Product$\lim (f g) = L M$
Quotient$\lim \frac{f}{g} = \frac{L}{M}$ if $M \ne 0$
Power and root$\lim f^n = L^n$, and $\lim \sqrt[n]{f} = \sqrt[n]{L}$ when the root is defined
Composition$\lim g(f(x)) = g(L)$ if $g$ is continuous at $L$

Together these say that polynomials, rational functions (away from zeros of the denominator), roots, $\sin$, $\cos$, $e^x$ and $\ln$ are continuous on their domains. For all of them, the limit is found by plugging in.

6. Techniques for $\frac{0}{0}$

When plugging in gives $\frac{0}{0}$, the expression is hiding a common factor that vanishes at $a$. The job is to expose and cancel it.

TechniqueExample
Factor and cancel$\lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} (x + 3) = 6$
Multiply by the conjugate$\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x} = \lim_{x \to 0} \frac{1}{\sqrt{x + 4} + 2} = \frac{1}{4}$
Known trig limit$\lim_{x \to 0} \frac{\sin 5x}{x} = 5 \lim_{u \to 0} \frac{\sin u}{u} = 5$
Trig identity$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \lim_{x \to 0} \frac{\sin^2 x}{x^2 (1 + \cos x)} = \frac{1}{2}$
L'Hôpital's ruleif $f(a) = g(a) = 0$, then $\lim \frac{f}{g} = \lim \frac{f'}{g'}$ when the right side exists

L'Hôpital's rule needs derivatives, which are themselves limits. It also handles $\frac{\infty}{\infty}$. Other indeterminate forms such as $0 \cdot \infty$, $\infty - \infty$, $1^\infty$, $0^0$ and $\infty^0$ are first rewritten into one of those two.

$\frac{0}{0}$ is not an answer. It is a sign that more work is needed.

7. The squeeze theorem

Sometimes you cannot simplify $f$, but you can trap it. If $g(x) \le f(x) \le h(x)$ near $a$, and $g$ and $h$ share the same limit $L$, then $f$ has no room to go anywhere else.

$$g \le f \le h \text{ near } a, \quad \lim_{x \to a} g = \lim_{x \to a} h = L \;\Rightarrow\; \lim_{x \to a} f = L$$

Fig 4 · $x^2 \sin\frac{1}{x}$ (dark) wiggles forever, but is pinned between $-x^2$ and $x^2$ (orange). Its limit at 0 is 0.

The same idea, with a geometric picture of the unit circle, shows $\cos x \le \frac{\sin x}{x} \le 1$ for small $x \ne 0$. Both bounds go to $1$, which gives the most used trig limit in calculus. It is the reason the derivative of $\sin x$ is $\cos x$.

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

8. Limits at infinity and infinite limits

Two other questions use the same language. What happens as $x$ grows without bound? And what happens when the output does?

$$\lim_{x \to \infty} f(x) = L \quad \text{(horizontal asymptote)} \qquad \lim_{x \to a} f(x) = \infty \quad \text{(vertical asymptote)}$$

For rational functions, divide top and bottom by the highest power of $x$ in the denominator. Every term $\frac{c}{x^k}$ with $k \ge 1$ goes to $0$, and the leading terms decide.

DegreesExampleLimit as x → ∞
top < bottom$\frac{5x + 1}{x^2 + 3}$$0$
top = bottom$\frac{3x^2 + 1}{x^2 - 5}$$3$, the ratio of leading coefficients
top > bottom$\frac{x^3}{x + 1}$$\infty$

Growth rates also order themselves: for large $x$, $\ln x \ll x^p \ll e^x \ll x!$ for any $p \gt 0$. So $\lim_{x \to \infty} \frac{x^{100}}{e^x} = 0$, even though the top wins for a very long time first.

One limit at infinity defines a constant. Compound interest at rate $100\%$ split into $n$ periods gives

$$e = \lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n \approx 2.71828$$

It is a $1^\infty$ form: the base tends to $1$ while the exponent tends to $\infty$, and neither wins outright.

9. Continuity

A function is continuous at $a$ when the limit equals the value:

$$\lim_{x \to a} f(x) = f(a)$$

That one line packs three checks: $f(a)$ exists, the limit exists, and they match. Each lab example breaks at least one of them.

DiscontinuityWhat breaksLab example
Removablethe limit exists, but $f(a)$ is missing or differentHole, sin x / x, Moved point
Jumpone-sided limits exist but differJump
Infinitethe output is unboundedBlow-up
Essential (oscillating)no one-sided limit existsOscillate

A removable discontinuity can be repaired by defining (or redefining) $f(a) = L$. Defining $\frac{\sin x}{x}$ to be $1$ at $0$ gives the smooth function called $\operatorname{sinc}$, which shows up in signal processing.

Why continuity pays off

The Intermediate Value Theorem says a function continuous on $[a, b]$ takes every value between $f(a)$ and $f(b)$. If $f(a) \lt 0 \lt f(b)$, there is a root in between. Bisection, the simplest root finder, is this theorem turned into a loop: halve the interval, keep the half where the sign changes, repeat.

10. The same thing in code

A computer can estimate a limit by evaluating closer and closer points. It works until floating point arithmetic gets in the way.

function estimateLimit(f, a) {
  for (let k = 1; k <= 7; k++) {
    const h = 10 ** -k;
    console.log(h, f(a - h), f(a + h));
  }
}

estimateLimit(x => Math.sin(x) / x, 0);      // both columns approach 1

// The trap: (1 - cos x) / x^2 should approach 0.5
const g = x => (1 - Math.cos(x)) / (x * x);
g(1e-4);   // 0.4999999969612645  (fine)
g(1e-8);   // 0                   (cos(1e-8) rounds to exactly 1)

// The fix is the same algebra as section 6: 1 - cos x = 2 sin^2(x/2)
const g2 = x => 2 * Math.sin(x / 2) ** 2 / (x * x);
g2(1e-8);  // 0.5000000000000001

Subtracting two nearly equal numbers loses digits, an effect called catastrophic cancellation. Rewriting the expression so the cancellation happens on paper, not in the machine, is the practical version of "factor and cancel".

11. Common mistakes

  • Treating $\frac{0}{0}$ as $0$, $1$ or "undefined, so no limit". It is indeterminate: the limit may be any number, or may not exist.
  • Checking only one side. A table that approaches from the right only can miss a jump.
  • Confusing $f(a)$ with $\lim_{x \to a} f(x)$. They agree only when $f$ is continuous at $a$.
  • Using $\infty$ as a number. $\infty - \infty$ and $\frac{\infty}{\infty}$ have no fixed value.
  • Trusting a few sample points. $\sin\frac{\pi}{x}$ is exactly $0$ at $x = 1, 0.1, 0.01, \dots$, yet it has no limit at $0$.

12. Where it shows up

  • Derivatives are the limit of secant slopes: $f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$.
  • Integrals are the limit of Riemann sums of thinner and thinner rectangles.
  • Series such as Taylor series are limits of partial sums.
  • Algorithms use limits to describe growth: $O(n \log n)$ is a statement about the ratio of two functions as $n \to \infty$.
  • Numerics: convergence of iterative methods such as Newton's method or gradient descent is a limit of a sequence.
