Eigenvalues and Eigenvectors

Most vectors get turned by a matrix. A few special ones only get stretched or flipped. Those directions, and the stretch factors along them, reveal what the matrix really does.

Try it first

Turn the blue vector $\mathbf{v}$ around the unit circle. The orange arrow is $A\mathbf{v}$, and the ellipse is the image of the whole circle. Most of the time the orange arrow points elsewhere. When it lines up with the blue one, you have found an eigenvector, and the ratio of lengths, with sign, is its eigenvalue $\lambda$. The dashed lines mark the eigen directions the matrix has.

1. The definition

  
A nonzero vector $\mathbf{v}$ is an eigenvector of the square matrix $A$ if multiplying by $A$ only scales it:

  
$$A\mathbf{v} = \lambda\mathbf{v}$$

  
The number $\lambda$ is the matching eigenvalue. If $\lambda = 2$ the vector is doubled. If $\lambda = -1$ it is flipped. If $\lambda = 0$ it is crushed to zero. Any nonzero multiple of an eigenvector is an eigenvector for the same $\lambda$, so what matters is the direction, a line through the origin. The set of all eigenvectors for one $\lambda$, plus $\mathbf{0}$, is a subspace called the eigenspace.

  
An eigenvector is a direction the matrix does not turn.






  
2. Finding them

  
Rewrite $A\mathbf{v} = \lambda\mathbf{v}$ as $(A - \lambda I)\mathbf{v} = \mathbf{0}$. A nonzero solution exists only when $A - \lambda I$ is not invertible, which means its determinant is zero:

  
$$\det(A - \lambda I) = 0$$

  
This is the characteristic equation. For a $2 \times 2$ matrix it is a quadratic with a simple form:

  
$$\lambda^2 - (a + d)\,\lambda + (ad - bc) = 0 \qquad\Longleftrightarrow\qquad \lambda^2 - \operatorname{tr}(A)\,\lambda + \det A = 0$$

  
Worked example. For $A = \begin{bmatrix}2&1\\1&2\end{bmatrix}$ the trace is $4$ and the determinant is $3$, so $\lambda^2 - 4\lambda + 3 = 0$ and $\lambda = 3$ or $\lambda = 1$. For $\lambda = 3$, solve $(A - 3I)\mathbf{v} = \mathbf{0}$, which says $-v_1 + v_2 = 0$, so $\mathbf{v} = (1, 1)$. For $\lambda = 1$ you get $\mathbf{v} = (1, -1)$. Check in the lab with the Symmetric preset: the dashed lines sit along those two directions.

4. Facts worth remembering

  
    
    
  • The sum of the eigenvalues is the trace. Their product is the determinant.
    • 
    
  • A matrix is invertible exactly when $0$ is not an eigenvalue.
    • 
    
  • For a triangular matrix, the eigenvalues are the diagonal entries.
    • 
    
  • Eigenvectors for different eigenvalues are linearly independent.
    • 
    
  • A symmetric real matrix has real eigenvalues and perpendicular eigenvectors.
    • 
    
  • $A^n$ has eigenvalues $\lambda^n$ with the same eigenvectors. That makes diagonalization so useful.
    •
