Eigenvalues and Eigenvectors

Most vectors get turned by a matrix. A few special ones only get stretched or flipped. Those directions, and the stretch factors along them, reveal what the matrix really does, and they decide what happens when you apply it over and over.

1. The definition

A nonzero vector $\mathbf{v}$ is an eigenvector of the square matrix $A$ if multiplying by $A$ only scales it:

$$A\mathbf{v} = \lambda\mathbf{v}, \qquad \mathbf{v} \neq \mathbf{0}$$

The number $\lambda$ is the matching eigenvalue. If $\lambda = 2$ the vector is doubled. If $\lambda = -1$ it is flipped. If $\lambda = 0$ it is crushed to zero. Any nonzero multiple of an eigenvector is an eigenvector for the same $\lambda$, so what matters is the direction, a line through the origin. The set of all eigenvectors for one $\lambda$, plus $\mathbf{0}$, is a subspace called the eigenspace.

An eigenvector is a direction the matrix does not turn.

"Eigen" is German for "own" or "characteristic": these are the matrix's own directions. They do not depend on any coordinate system you choose, which is why they describe the transformation itself rather than its numbers.

2. Finding them

Rewrite $A\mathbf{v} = \lambda\mathbf{v}$ as $(A - \lambda I)\mathbf{v} = \mathbf{0}$. A nonzero solution exists only when $A - \lambda I$ squashes some direction to zero, that is, when it is not invertible. By the determinant test:

$$\det(A - \lambda I) = 0$$

This is the characteristic equation. Its left side is a polynomial of degree $n$ in $\lambda$, so an $n \times n$ matrix has exactly $n$ eigenvalues counted with multiplicity, some possibly complex. For a $2 \times 2$ matrix it has a simple form:

$$\lambda^2 - (a + d)\,\lambda + (ad - bc) = 0 \qquad\Longleftrightarrow\qquad \lambda^2 - \operatorname{tr}(A)\,\lambda + \det A = 0$$

Once you have a $\lambda$, the eigenvectors are the null space of $A - \lambda I$, found by elimination.

Worked example: symmetric

For $A = \begin{bmatrix}2&1\\1&2\end{bmatrix}$ the trace is $4$ and the determinant is $3$, so $\lambda^2 - 4\lambda + 3 = (\lambda - 3)(\lambda - 1) = 0$. For $\lambda = 3$, $(A - 3I)\mathbf{v} = \mathbf{0}$ reads $-v_1 + v_2 = 0$, so $\mathbf{v} = (1, 1)$. For $\lambda = 1$ you get $\mathbf{v} = (1, -1)$. The two directions are perpendicular, which is typical for symmetric matrices.

Worked example: not symmetric

  1. $A = \begin{bmatrix}4&1\\2&3\end{bmatrix}$: $\operatorname{tr} = 7$, $\det = 10$, so $\lambda^2 - 7\lambda + 10 = (\lambda - 5)(\lambda - 2) = 0$.
  2. $\lambda = 5$: $A - 5I = \begin{bmatrix}-1&1\\2&-2\end{bmatrix}$, so $v_1 = v_2$ and $\mathbf{v} = (1, 1)$.
  3. $\lambda = 2$: $A - 2I = \begin{bmatrix}2&1\\2&1\end{bmatrix}$, so $2v_1 + v_2 = 0$ and $\mathbf{v} = (1, -2)$.
  4. Check: $A(1, -2) = (4 - 2,\ 2 - 6) = (2, -4) = 2(1, -2)$. The eigenvectors are not perpendicular this time.

Load "Non-symmetric" in the lab and drag $\mathbf{v}$ onto each dashed line to confirm.

Larger matrices

For a triangular matrix the determinant of $A - \lambda I$ is the product of its diagonal, so the eigenvalues can be read off directly: $\begin{bmatrix}2&1&0\\0&3&1\\0&0&5\end{bmatrix}$ has eigenvalues $2, 3, 5$. In general, the characteristic polynomial of a $5 \times 5$ or larger matrix has no formula for its roots, so software never solves it. It uses iterative methods like the QR algorithm instead.

3. Three things that can happen

For $2 \times 2$ matrices the quadratic formula gives $\lambda = \frac{\operatorname{tr} \pm \sqrt{\operatorname{tr}^2 - 4\det}}{2}$, and the sign under the square root decides the picture.

Complex eigenvalues are not a failure. The rotation by angle $\theta$ has characteristic equation $\lambda^2 - 2\cos\theta\,\lambda + 1 = 0$, with roots $\cos\theta \pm i\sin\theta = e^{\pm i\theta}$. The modulus $|\lambda|$ is the scaling and the argument is the rotation angle. See Euler's Formula for why $e^{i\theta}$ is a spin. In the lab, the turn plot for the rotation never crosses zero.

4. Repeated eigenvalues

A repeated root can hide two very different matrices. Both have $\lambda = 1$ twice:

$$I = \begin{bmatrix}1&0\\0&1\end{bmatrix} \qquad S = \begin{bmatrix}1&1\\0&1\end{bmatrix}$$

For $I$, every vector is an eigenvector: the eigenspace is the whole plane. For the shear $S$, $(S - I)\mathbf{v} = (v_2, 0) = \mathbf{0}$ forces $v_2 = 0$, so only the horizontal line survives. The number of times $\lambda$ is a root is its algebraic multiplicity; the dimension of its eigenspace is its geometric multiplicity. The geometric one is never larger. When it is strictly smaller, as for the shear, the matrix is called defective and cannot be diagonalized.

6. Power iteration

Write a starting vector in terms of eigenvectors, $\mathbf{x}_0 = c_1\mathbf{v}_1 + c_2\mathbf{v}_2$, with $|\lambda_1| \gt |\lambda_2|$. Applying $A$ $k$ times multiplies each piece by its eigenvalue:

$$A^k\mathbf{x}_0 = c_1\lambda_1^k\mathbf{v}_1 + c_2\lambda_2^k\mathbf{v}_2 = \lambda_1^k\left(c_1\mathbf{v}_1 + c_2\left(\tfrac{\lambda_2}{\lambda_1}\right)^k\mathbf{v}_2\right)$$

The second term shrinks like $\left|\frac{\lambda_2}{\lambda_1}\right|^k$, so the direction locks onto $\mathbf{v}_1$. Normalizing each step keeps the numbers from blowing up. For the symmetric example the ratio is $\frac{1}{3}$: each step cuts the error by three. For the "Stretch" preset it is $\frac{1}{4}$; try a matrix with nearly equal eigenvalues and watch it crawl. With a complex pair there is no dominant real direction, and the iterates keep circling.

The estimate of $\lambda_1$ is the Rayleigh quotient $\frac{\mathbf{x}^{\mathsf T}A\mathbf{x}}{\mathbf{x}^{\mathsf T}\mathbf{x}}$, shown in the readout.

7. Eigenvalues decide the long run

Many systems step forward by a fixed matrix, $\mathbf{x}_{k+1} = A\mathbf{x}_k$. Then $\mathbf{x}_k = A^k\mathbf{x}_0$, and the eigenvalues say everything about the future:

  • All $|\lambda| \lt 1$: everything decays to zero. The system is stable.
  • Some $|\lambda| \gt 1$: growth along that eigenvector dominates.
  • $\lambda = 1$: a steady state. Markov chains always have one.
  • Complex $\lambda$: spiralling, with $|\lambda|$ deciding in or out.

Fibonacci

The step $(F_{k+1}, F_k) \to (F_{k+1} + F_k,\ F_{k+1})$ is the matrix $\begin{bmatrix}1&1\\1&0\end{bmatrix}$. Its characteristic equation is $\lambda^2 - \lambda - 1 = 0$, with roots $\varphi = \frac{1 + \sqrt{5}}{2} \approx 1.618$ and $\psi = \frac{1 - \sqrt{5}}{2} \approx -0.618$. Since $|\psi| \lt 1$, its part fades and

$$F_k = \frac{\varphi^k - \psi^k}{\sqrt{5}} \approx \frac{\varphi^k}{\sqrt{5}}, \qquad \text{e.g. } \frac{\varphi^{20}}{\sqrt{5}} \approx 6765.00003 \text{ and } F_{20} = 6765$$

Load the "Fibonacci" preset: power iteration lines up with the golden-ratio direction $(\varphi, 1)$.

Differential equations

For continuous time, $\mathbf{x}'(t) = A\mathbf{x}(t)$ has solutions $e^{\lambda t}\mathbf{v}$ along each eigenvector. Now the real part of $\lambda$ decides: negative real parts mean decay, positive mean growth, and imaginary parts mean oscillation. Engineers check stability of a control system by checking where its eigenvalues lie.

8. Symmetric matrices and ellipses

When $A$ is symmetric, the ellipse in the lab has its axes exactly along the eigenvectors, and the half-axis lengths are $|\lambda_1|$ and $|\lambda_2|$. That is the spectral theorem in a picture: a symmetric matrix is a pure stretch along perpendicular axes, $A = Q\Lambda Q^{\mathsf T}$ with $Q$ orthogonal. For a non-symmetric matrix the ellipse axes and the eigenvectors no longer agree; the ellipse axes then come from the singular value decomposition.

The same fact explains principal component analysis. The covariance matrix of a data cloud is symmetric. Its eigenvectors are the directions of greatest and least spread, and its eigenvalues are the variances along them.

9. The same thing in code

// Closed form for 2x2: roots of λ² − tr·λ + det
function eig2([[a, b], [c, d]]) {
  const tr = a + d, det = a * d - b * c, disc = tr * tr - 4 * det;
  if (disc < 0) return { re: tr / 2, im: Math.sqrt(-disc) / 2 };   // complex pair
  return [(tr + Math.sqrt(disc)) / 2, (tr - Math.sqrt(disc)) / 2];
}

// Power iteration: dominant eigenvalue and eigenvector of any size
function power(A, steps = 50) {
  let x = A.map(() => 1), lambda = 0;
  for (let k = 0; k < steps; k++) {
    const y = A.map(row => row.reduce((s, a, j) => s + a * x[j], 0));
    const n = Math.hypot(...y);
    lambda = y.reduce((s, yi, i) => s + yi * x[i], 0);   // Rayleigh quotient (x has length 1)
    x = y.map(v => v / n);
  }
  return { lambda, x };
}

eig2([[4, 1], [2, 3]]);   // [5, 2]
power([[2, 1], [1, 2]]);  // lambda ≈ 3, x ≈ [0.7071, 0.7071]

Starting from $(1, 0)$ instead, the Rayleigh estimates for the symmetric example run $2.8,\ 2.976,\ 2.9973,\ 2.99970, \ldots$: one more correct digit per step, matching the ratio $\frac{1}{3}$. For real work use a library routine (numpy.linalg.eig, LAPACK), which runs the QR algorithm and handles complex and repeated cases.

10. Common mistakes

  • Counting $\mathbf{0}$ as an eigenvector. It satisfies $A\mathbf{0} = \lambda\mathbf{0}$ for every $\lambda$, which is why it is excluded.
  • Row-reducing $A$ first. Row operations change the eigenvalues; only $A - \lambda I$ may be reduced, and only to find eigenvectors.
  • Adding eigenvalues of $A$ and $B$ to get those of $A + B$. That only works when they share eigenvectors.
  • Assuming real matrices have real eigenvalues. A rotation shows otherwise.
  • Expecting $n$ independent eigenvectors. The shear has only one.

11. Where it shows up

Search
PageRank

The ranking vector is the eigenvector with eigenvalue 1 of the web's link matrix, found by power iteration.

Data
PCA

The principal axes of a data cloud are eigenvectors of its covariance matrix.

Physics
vibration

Natural frequencies and mode shapes of a bridge or a molecule are eigenvalues and eigenvectors.

Quantum mechanics
observables

Measurable values are eigenvalues of an operator; the energy levels of an atom are eigenvalues of its Hamiltonian.

Graphs
spectral clustering

Eigenvectors of the graph Laplacian split a network into communities.

Finance
risk factors

The top eigenvectors of a return covariance matrix are market-wide factors; the top one is usually "the market".
