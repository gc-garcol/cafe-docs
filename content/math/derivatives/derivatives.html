Derivatives

The derivative is the instant rate of change: the slope of a curve at a single point. It is what you get when a secant line is squeezed into a tangent.

Try it first

The blue line is a secant through two points of the curve, $x = a$ and $x = a + h$. Shrink $h$ and watch it rotate into the dashed orange tangent. The secant slope turns into the derivative.

secant tangent curve

1. Average vs instant rate

A car drives 60 km in 1 hour. Its average speed is 60 km/h. That is the slope of the secant between two moments. The speedometer shows something sharper: the speed right now, with the time gap shrunk to nothing.

Average rate over a gap, then let the gap go to zero.

2. The definition

The slope between $(a, f(a))$ and $(a + h, f(a + h))$ is the difference quotient. The derivative is its limit as $h \to 0$. If this limit does not exist, $f$ has no derivative at $a$.

$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$

Worked example with $f(x) = x^2$:

$$\frac{(a+h)^2 - a^2}{h} = \frac{2ah + h^2}{h} = 2a + h \to 2a$$

So the slope of $x^2$ at any point is $2a$. At $a = 1.5$ the slope is exactly $3$, which you can check with the panel above.

Fig 2 · Differentiable means smooth: no corner, no break, no vertical tangent. Differentiable implies continuous, but not the other way around.

4. Rules you actually use

Nobody computes the limit each time. These rules cover most cases.

RuleDerivative
Constant$(c)' = 0$
Power$(x^n)' = n x^{n-1}$
Sum, constant multiple$(c f + g)' = c f' + g'$
Product$(f g)' = f' g + f g'$
Quotient$\left(\frac{f}{g}\right)' = \frac{f' g - f g'}{g^2}$
Chain$(f(g(x)))' = f'(g(x))\,g'(x)$
Exponential, log$(e^x)' = e^x$, $(\ln x)' = \frac{1}{x}$
Trig$(\sin x)' = \cos x$, $(\cos x)' = -\sin x$

Example with the chain rule: $\frac{d}{dx}\sin(x^2) = \cos(x^2) \cdot 2x$.

5. What the slope tells you

f′ > 0
rising

The function increases around that point.

f′ < 0
falling

The function decreases around that point.

f′ = 0
flat

A candidate for a peak, a valley, or a flat bend. Check the sign on both sides.

That last case is how you optimize: set $f'(x) = 0$, solve, and test the candidates. It is also the base of gradient descent in machine learning, where the slope tells you which way is downhill.

The second derivative $f''$ measures how the slope itself changes. Positive means the curve bends up like a bowl, negative means it bends down like a hill.
