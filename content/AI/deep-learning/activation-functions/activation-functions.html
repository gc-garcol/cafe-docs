Activation Functions

The small nonlinear bend after every layer. Without it a deep network is just one linear map. With the wrong one, gradients fade to nothing before they reach the first layer.

1. Why a network needs one

  
A layer computes $W\mathbf{x} + \mathbf{b}$. Feed that into the next layer and you get $W_2(W_1\mathbf{x}+\mathbf{b}_1)+\mathbf{b}_2$, which is still a matrix times $\mathbf{x}$ plus a vector. Any number of purely linear layers collapse into one. The activation $f$ breaks this:

  
$$\mathbf{h} = f(W\mathbf{x} + \mathbf{b})$$

  
Applied entry by entry, it lets the network bend its decision boundary. See the Deep Learning Overview lab, where a single neuron draws only a line.

  
No nonlinearity, no depth. A hundred linear layers equal one.






  
2. The common choices

  

    
NameFormulaRangeNotes

    
      
Sigmoid$\dfrac{1}{1+e^{-z}}$$(0,1)$A probability. Slope never exceeds $0.25$.

      
Tanh$\tanh z$$(-1,1)$Zero centered. Slope up to $1$ at $z=0$.

      
ReLU$\max(0,z)$$[0,\infty)$Cheap. Slope is exactly $1$ when active.

      
Leaky ReLU$\max(\alpha z, z)$$(-\infty,\infty)$Small slope $\alpha$ on the negative side keeps neurons alive.

      
GELU$z\,\Phi(z)$$\approx[-0.17,\infty)$A smooth ReLU. Common in transformers.

    
  

  
Here $\Phi$ is the standard normal cumulative distribution function. The lab uses $\alpha = 0.1$ for Leaky ReLU, and the common tanh approximation for GELU.






  
3. Vanishing and dying gradients

  
Backpropagation multiplies one slope per layer. If every slope is below $1$, the product shrinks exponentially with depth:

  
$$\frac{\partial L}{\partial \mathbf{h}_1} \;\propto\; \prod_{l=1}^{n} f'(z_l)\;\le\; \big(\max f'\big)^{n}$$

  
Sigmoid has $\max f' = 0.25$, so ten layers shrink the signal by at least $0.25^{10} \approx 10^{-6}$. The early layers barely learn. Move the Layers slider and compare. This is only the best case and ignores the weights, so real gradients are usually smaller still.

  
    
    
  • Saturation. At large $|z|$, sigmoid and tanh go flat and the slope is near zero. Drag $z$ to $4$ and read the slope.
    • 
    
  • Dying ReLU. If $z<0$ for every input, the slope is $0$ and the neuron never updates again. Leaky ReLU and GELU keep a small gradient there.
    • 
    
  • Exploding gradients. A slope above $1$ repeated many times grows instead. Initialization, normalization and gradient clipping handle this.
    • 
  






  
4. Which one to pick

  
    
    
  • Hidden layers: start with ReLU. Try Leaky ReLU or GELU if many neurons go silent, and GELU for transformers.
    • 
    
  • Output for two classes: sigmoid, paired with cross-entropy loss.
    • 
    
  • Output for many classes: softmax, $\dfrac{e^{z_i}}{\sum_j e^{z_j}}$, so the outputs sum to $1$.
    • 
    
  • Output for a real number: no activation (identity).
    • 
  






  
5. The same thing in code

  
const sigmoid = z => 1 / (1 + Math.exp(-z));
const relu    = z => Math.max(0, z);
const leaky   = (z, a = 0.1) => (z > 0 ? z : a * z);

// slopes used by backpropagation
const dSigmoid = z => { const s = sigmoid(z); return s * (1 - s); };
const dTanh    = z => 1 - Math.tanh(z) ** 2;
const dRelu    = z => (z > 0 ? 1 : 0);

function softmax(zs) {
  const m = Math.max(...zs);            // subtract the max for stability
  const e = zs.map(z => Math.exp(z - m));
  const s = e.reduce((a, b) => a + b, 0);
  return e.map(v => v / s);
}
