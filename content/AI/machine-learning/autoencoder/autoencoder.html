Autoencoder

A network trained to copy its input through a narrow gap. To succeed, the gap has to hold the few numbers that really describe the data.

#unsupervised#neural network#bottleneck#reconstruction

Try it first

The points lie on a curve in 2D, so one number is enough to describe each of them. This autoencoder squeezes every point to one number and rebuilds two. Train with linear layers and the best it can do is a straight line, which is what PCA finds. Switch on the nonlinear version and the decoder learns to bend.

Readout

    

  






  
1. Learn to copy, through a bottleneck

  
An autoencoder has two halves. The encoder $f$ maps an input $x$ to a short code $z$. The decoder $g$ maps $z$ back to a reconstruction $\hat x$. It trains with no labels, to make the output match the input:

  
$$z=f(x),\qquad \hat x=g(z),\qquad L=\frac1n\sum_i\|x_i-\hat x_i\|^2$$

  
If the code were as wide as the input, the network could just copy. A narrow code forces it to keep only what matters. That is why this is called self-supervised: the input is its own target.






  
2. Linear case equals PCA

  
With linear layers and squared error, the best autoencoder spans the same subspace as PCA. The orange curve stays a straight line, and the error stays high on a curved arc.






  
3. Nonlinear case

  
Add nonlinear activations, such as tanh, and the decoder can trace a curved sheet through the data, called a manifold. The same one-number code now reconstructs the arc nearly perfectly. Click Train a few times to watch the curve settle onto the data.

5. Uses and cautions

  
    
    
  • Dimensionality reduction, like a nonlinear PCA, and features for later models.
    • 
    
  • Anomaly detection: data unlike the training set reconstructs badly, so a large error is a flag.
    • 
    
  • Too much capacity lets it memorize. Use a small code, regularization or noise.
    • 
    
  • Unlike t-SNE, it can encode new points.
    •
