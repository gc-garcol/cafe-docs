t-SNE

Squash many dimensions onto a flat map so that points that were neighbors stay neighbors. Built for looking at data, not for modeling it.

1. The goal

  
PCA keeps directions of largest variance, which are linear. Curved or tangled structure gets lost. t-SNE, t-distributed Stochastic Neighbor Embedding, instead tries to preserve who is near whom.






  
2. Step 1: neighbor probabilities in high dimension

  
For each point $i$, turn distances into the probability that $j$ is its neighbor, using a Gaussian centered on $i$:

  
$$p_{j\mid i}=\frac{\exp(-\|x_i-x_j\|^2/2\sigma_i^2)}{\sum_{k\ne i}\exp(-\|x_i-x_k\|^2/2\sigma_i^2)}$$

  
The width $\sigma_i$ is chosen per point so that the distribution has a set perplexity, roughly the effective number of neighbors. Dense areas get small $\sigma_i$, sparse ones large. The result is symmetrized into $p_{ij}$.






  
3. Step 2: the same in 2D, with heavy tails

  
Place points $y_i$ on the plane and define similarity with a Student-t curve, which has far fatter tails than a Gaussian:

  
$$q_{ij}=\frac{(1+\|y_i-y_j\|^2)^{-1}}{\sum_{k\ne l}(1+\|y_k-y_l\|^2)^{-1}}$$

  
The fat tail lets moderately distant points sit far apart in 2D, which fixes the "crowding" problem of squeezing high dimensions into two.






  
4. Step 3: make the two agree

  
Move the $y_i$ by gradient descent to minimize the mismatch between $P$ and $Q$, measured by KL divergence:

  
$$C=\sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$$

  
It punishes placing true neighbors far apart much more than the reverse. A trick called early exaggeration scales $p_{ij}$ up at the start so clusters form first.






  
5. How to read a t-SNE plot

  
    
    
  • Clusters are meaningful. Distances between clusters and cluster sizes are not.
    • 
    
  • Run it with several perplexities, typically 5 to 50. Different values can show different structure.
    • 
    
  • Results change with the random start. A cluster that appears in every run is more trustworthy.
    • 
    
  • It does not give a function for new points. For that, use PCA or an Autoencoder. UMAP is a faster relative.
    •
