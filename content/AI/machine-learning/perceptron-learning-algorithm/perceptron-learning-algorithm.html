Perceptron Learning Algorithm

The first learning machine. A perceptron draws a line between two classes, and every time it misclassifies a point it tilts the line toward getting that point right.

1. The model

  
A perceptron takes a weighted sum of the inputs, adds a bias, and reports only its sign. The weights $\mathbf{w}$ and bias $b$ define a line in 2D, a plane in 3D, and a hyperplane in general.

  
$$\hat{y} = \operatorname{sign}\!\left(\mathbf{w}^\top \mathbf{x} + b\right)$$

  
The vector $\mathbf{w}$ is perpendicular to the boundary and points toward the $+1$ side. That is the arrow in the lab. The bias slides the line away from the origin. Labels are $y \in \{+1, -1\}$, so a prediction is right exactly when $y\,(\mathbf{w}^\top \mathbf{x} + b) > 0$.






  
2. The learning rule

  
Start with all weights at zero. Look at the points one by one. If a point is classified correctly, do nothing. If it is wrong, pull the boundary toward it:

  
$$\mathbf{w} \leftarrow \mathbf{w} + y\,\mathbf{x}, \qquad b \leftarrow b + y$$

  
Why does this help? For the point just updated, the quantity $y\,(\mathbf{w}^\top \mathbf{x} + b)$ grows by exactly $\lVert\mathbf{x}\rVert^2 + 1$, which is always positive. The point is not always fixed in one step, but it always ends up closer to the right side. One mistake fixed can break others, so the loop keeps going over the data.

  
    
    
  1. Set $\mathbf{w} = \mathbf{0}$ and $b = 0$.

  2. Scan the points. For each one with $y\,(\mathbf{w}^\top\mathbf{x} + b) \le 0$, apply the update.
    3. 
    
  3. If a full pass makes no update, stop. Otherwise scan again.
    4. 
  

  
The perceptron only learns from its mistakes. Points it already gets right change nothing.






  
3. When it is guaranteed to stop

  
Say the data is linearly separable with margin $\gamma$, meaning some unit vector separates the classes with every point at least $\gamma$ from the line. Say all points lie within a ball of radius $R$. Novikoff's theorem then bounds the total number of updates, whatever the order:

  
$$\text{mistakes} \le \left(\frac{R}{\gamma}\right)^2$$

  
The bound does not depend on the number of points or the dimension. A wide gap between the classes means few mistakes. In the lab, the Separable set always finishes. Press Run to the end and read the update count.






  
4. When it never stops

  
If no line separates the classes, some point is always misclassified, so every pass triggers an update and the weights wander forever. Pick Overlapping or XOR and press Run. The run gives up after 200 passes, with the mistake count never reaching zero.

  
XOR is the famous case: the $+1$ points sit on one diagonal and the $-1$ points on the other, and no single line can split them. This limit was a big blow to early neural network research. The fix is to stack layers of perceptrons or to add features such as the product $x_1 x_2$. Another route is to replace the hard sign with a smooth function so that Gradient Descent applies, which leads to Logistic Regression.






  
5. The same thing in code

  
function train(points, labels, maxPasses = 200) {
  let w = [0, 0], b = 0;
  for (let pass = 0; pass < maxPasses; pass++) {
    let updates = 0;
    points.forEach((x, i) => {
      const score = w[0] * x[0] + w[1] * x[1] + b;
      if (labels[i] * score <= 0) {        // wrong or on the line
        w[0] += labels[i] * x[0];
        w[1] += labels[i] * x[1];
        b += labels[i];
        updates++;
      }
    });
    if (updates === 0) return { w, b, pass };   // converged
  }
  return { w, b, pass: maxPasses };            // not separable
}






  
6. Where it fits

  

    
History
1958
Frank Rosenblatt built it in hardware. It is the ancestor of the neuron in every neural network.

    
Strength
tiny
No learning rate, no probabilities, just additions. It works online, one example at a time.

    
Weakness
hard edge
It only says yes or no, with no confidence, and it fails on data a line cannot separate.

  

  
Compare it with Logistic Regression, which keeps the same linear score but turns it into a probability, and with Linear Regression, which predicts a number. The full family tree is in Machine Learning Algorithm Groups.
