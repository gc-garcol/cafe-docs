Ridge and Lasso Regression

Linear regression with a leash. Add a penalty on the size of the weights and the model trades a little bias for much less variance.

1. The problem with plain least squares

  
Ordinary least squares picks the weights with the smallest training error. With few points, many features or features that move together, it will use large weights of opposite signs to fit noise. The model then looks great on training data and does badly on new data. That is overfitting.

  
Regularization adds a price for large weights, so the model only keeps a weight if it earns its place.






  
2. Ridge: penalize squared weights

  
Ridge adds the sum of squared weights to the loss:

  
$$\min_{w}\; \frac{1}{2n}\sum_{i=1}^{n}\big(y_i - w^\top x_i\big)^2 \;+\; \frac{\lambda}{2}\sum_{j=1}^{d} w_j^2$$

  
It still has a closed form, $w=(X^	op X/n+\lambda I)^{-1}X^	op y/n$. Adding $\lambda I$ also makes the matrix invertible when features are correlated. Ridge shrinks all weights toward zero but rarely makes one exactly zero.






  
3. Lasso: penalize absolute weights

  
Lasso swaps the square for the absolute value:

  
$$\min_{w}\; \frac{1}{2n}\sum_{i=1}^{n}\big(y_i - w^\top x_i\big)^2 \;+\; \lambda\sum_{j=1}^{d} |w_j|$$

  
The sharp corner of $|w|$ at zero lets weights land exactly on zero, so Lasso also does feature selection. There is no closed form, so it is solved by coordinate descent. Each step applies the soft threshold $S(z,\lambda)=\operatorname{sign}(z)\max(|z|-\lambda,0)$ to one weight.






  
4. Choosing lambda

  
The right-hand curve is the story. Training error only rises with $\lambda$. Test error falls first, as variance drops, then rises, as the model becomes too stiff. Pick the $\lambda$ at the bottom of the test curve, using cross-validation rather than a test set you will reuse.

  
    
    
  • Standardize features first. The penalty treats all weights alike, so their scales must match.
    • 
    
  • Do not penalize the intercept.
    • 
    
  • Elastic Net mixes both penalties. It helps when correlated features should be kept or dropped together.
