Monte Carlo Tree Search

Find a good move without knowing a good evaluation. Play thousands of random games, and steer more of them toward the moves that look promising.

#reinforcement learning#mcts#uct#tree search

Try it first

Tic-tac-toe, with X to move. Pick a position, press Run, and the board fills with each move's visit count and win rate. Search effort piles up on the strongest move, and the most visited one is chosen. Try the "win now" position with only 20 simulations, then with 1000.

Readout

    

  






  
1. Search with samples instead of knowledge

  
A classic game program needs an evaluation function: a score for any board. For Go and many other games, nobody could write a good one. Monte Carlo Tree Search (MCTS) replaces it with simulation: to judge a move, play many random games to the end and count wins.

  
Pure random playouts waste time on bad moves. MCTS grows a tree and spends more playouts on promising branches.






  
2. Four steps, repeated

  
  1. Select. From the root, repeatedly go to the child with the best score until you reach a node that still has untried moves.
  2. Expand. Add one new child for an untried move.
  3. Simulate. From the new node, play random moves to the end of the game.
  4. Backpropagate. Add the result to every node on the path back up: a visit, and a win if it was a win for the player who moved there.

  
After many rounds, play the root child with the most visits. Visits are a steadier signal than raw win rate.






  
3. How to select: UCT

  
Always choosing the highest win rate would stop exploring. Always exploring wastes effort. UCB1 balances them with a score for each child:

  
$$\text{UCT}=\frac{w_i}{n_i}+c\sqrt{\frac{\ln N}{n_i}}$$

  
Here $w_i/n_i$ is the win rate (exploit), $n_i$ the child's visits, and $N$ the parent's visits. The second term grows for rarely tried children (explore). The constant $c$ sets the balance, often near $\sqrt2$. Set it to 0 and watch search lock on early.






  
4. Properties

  
    
    
  • It is anytime: stop whenever you like and use the current best.
    • 
    
  • It needs only the rules, no hand-made evaluation, and works for large branching.
    • 
    
  • The result improves with more simulations, and converges to optimal play.
    • 
    
  • Random playouts are weak in tactical positions. AlphaGo and AlphaZero replace them with a neural network for position value and move priors, and keep the tree search.
    •
