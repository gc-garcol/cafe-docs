k-Nearest Neighbors

The laziest useful classifier. It learns nothing in advance. To label a new point, it finds the $k$ closest known points and lets them vote.

1. The idea

  
Similar inputs tend to have similar labels. So to predict for a new point $x$, look at the training points closest to it. K-NN has no training step and no parameters to fit. The data is the model, which is why it is called a lazy or instance-based learner.

  
Do not learn a rule. Remember everything and ask the neighbors.






  
2. The rule

  
Measure distance, usually Euclidean, from the query to every training point:

  
$$d(x, x_i) = \sqrt{\sum_{j=1}^{d} (x_j - x_{i,j})^2}$$

  
Let $N_k(x)$ be the $k$ points with the smallest distance. The predicted class is the most common label among them, which is also an estimate of the class probability:

  
$$\hat{P}(c \mid x) = \frac{1}{k}\sum_{x_i \in N_k(x)} \mathbb{1}[y_i = c], \qquad \hat{y} = \arg\max_c \hat{P}(c \mid x)$$

  
For regression, replace the vote with the average of the neighbors' values.






  
3. Choosing k

  

    
Small k
wiggly
$k=1$ copies the nearest point, noise included. Low bias, high variance, and the model overfits.

    
Large k
smooth
The vote averages over a wide area. The boundary is stable, but real structure gets washed out.

    
In practice
validate
Try several odd values of $k$ on held-out data and keep the best. Odd $k$ avoids ties with two classes.

  






  
4. What can go wrong

  
    
    
  • Scale. Distance adds all features together, so a feature in thousands drowns one in tenths. Standardize first.
    • 
    
  • Many dimensions. In high dimensions all points become almost equally far apart, and "nearest" loses meaning. Reduce dimensions first, for example with PCA.
    • 
    
  • Cost. A query scans all $n$ points, $O(nd)$. Spatial indexes such as a k-d tree or a Quad Tree prune most of that in low dimensions.
    • 
    
  • Memory. You must keep the whole training set.
    • 
  






  
5. The same thing in code

  
function knnPredict(train, query, k) {
  // distance from the query to every labeled point
  const byDist = train
    .map(p => ({ label: p.label, d: dist(p.x, query) }))
    .sort((a, b) => a.d - b.d)
    .slice(0, k);

  // majority vote
  const votes = {};
  for (const n of byDist) votes[n.label] = (votes[n.label] || 0) + 1;
  return Object.entries(votes).sort((a, b) => b[1] - a[1])[0][0];
}






  
6. Related

  
K-NN draws curved boundaries without any equations. A linear model such as Logistic Regression or the Perceptron draws a straight one and is far cheaper at prediction time. K-means also uses distance, but without labels. See the full map in Machine Learning Algorithm Groups.
