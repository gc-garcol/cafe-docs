1. The main axis: what feedback is there?

  
The first question to ask is what the algorithm is told while it learns. That one choice splits almost everything into three big families.

  

    
Supervised
labels
Every example comes with the right answer. The model learns to predict that answer for new inputs.

    
Unsupervised
structure
No answers at all. The model looks for groups, directions or patterns that are already in the data.

    
Reinforcement
rewards
An agent acts, then gets a score. It learns which sequence of actions earns the most over time.

  

  
Two smaller groups sit between them. Semi-supervised methods use a few labels and many unlabeled examples. Self-supervised methods invent labels from the data itself, such as hiding a word and predicting it.

  
Supervised learning has a compact definition. Given pairs $(x_i, y_i)$, find parameters $\theta$ that make the model $f_\theta$ agree with the answers:

  
$$\min_{\theta}\; \frac{1}{n}\sum_{i=1}^{n} L\big(f_\theta(x_i),\, y_i\big)$$

  
Here $L$ is a loss that grows when the prediction is wrong. Unsupervised learning has no $y_i$, so the loss compares the model to the data itself. K-means, for example, minimizes the squared distance from each point to its cluster center.






  
2. The second axis: what job is it doing?

  
Inside each family, algorithms are grouped by the kind of answer they produce.

  

  

    
TaskFamilyOutputExample algorithms

    
      
RegressionSupervisedA numberLinear Regression, decision trees, random forests

      
ClassificationSupervisedA class label or probabilityLogistic Regression, Perceptron, SVM, k-NN

      
ClusteringUnsupervisedA group id for each pointK-means, DBSCAN, hierarchical

      
Dimensionality reductionUnsupervisedFewer coordinates per pointPCA, t-SNE, autoencoders

      
Control and decisionsReinforcementAn action for each situationQ-learning, policy gradients

    
  

  

  
Regression answers "how much?". Classification answers "which one?". Clustering answers "which belong together?".






  
3. Other ways to group the same algorithms

  
The same algorithm can be placed on several axes at once. These views cut across the tree and help you predict how a method behaves.

  

  

    
AxisOne sideOther side

    
      
Model sizeParametric: a fixed number of parameters, such as the weights of a line.Non-parametric: the model grows with the data, such as k-NN or decision trees.

      
What is modeledDiscriminative: learns the boundary $P(y\mid x)$, such as logistic regression.Generative: learns how data is produced, $P(x, y)$, such as naive Bayes.

      
Shape of the modelLinear: a weighted sum of inputs, then maybe a squashing function.Non-linear: trees, kernels and neural networks bend the boundary.

      
How it is trainedClosed form: solve an equation once, such as least squares.Iterative: improve step by step with Gradient Descent.

    
  

  

  
Optimization is not a family of models, it is the engine under many of them. Gradient descent trains linear models, logistic regression and neural networks alike, which is why it has its own group in the tree above.






  
4. How to choose a group

  
    
    
  • Do you have the right answers for past examples? Start with supervised learning.
    • 
    
  • Is the answer a number or a category? Number means regression, category means classification.
    • 
    
  • No answers, but you want groups or a simpler view? Use clustering or dimensionality reduction.
    • 
    
  • Does the model act, and does each action change what comes next? Look at reinforcement learning.
    • 
    
  • Start with the simplest linear model. It trains fast, it is easy to explain, and it sets a baseline for anything fancier.
    •
