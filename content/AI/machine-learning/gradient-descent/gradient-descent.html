1. The idea

  
A model has weights $\theta$ and a loss $L(\theta)$ that measures how wrong it is. Training means finding the $\theta$ with the smallest loss. The gradient $\nabla L(\theta)$ is the vector of slopes, one per weight. It points uphill, in the direction where the loss grows fastest. So to go down, step the other way.

  
$$\theta \leftarrow \theta - \eta\, \nabla L(\theta)$$

  
The number $\eta$ is the learning rate, the size of each step. This single line is the whole algorithm. Everything else is about computing $\nabla L$ cheaply and choosing $\eta$ well.

  
Slope tells you the direction. The learning rate tells you how far to trust it.






  
2. The valley in the lab

  
The loss in Fig 1 is a simple bowl with one steep and one shallow direction. The slider $a$ sets how much steeper the vertical direction is.

  
$$L(x, y) = \tfrac{1}{2}\left(x^2 + a\,y^2\right), \qquad \nabla L = \begin{bmatrix} x \\ a\,y \end{bmatrix}$$

  
One step multiplies each coordinate by a fixed factor: $x \leftarrow (1-\eta)\,x$ and $y \leftarrow (1-\eta a)\,y$. A coordinate shrinks to zero only when its factor has size below 1. For the steep direction that means:

  
$$|1 - \eta a| < 1 \quad\Longleftrightarrow\quad \eta < \frac{2}{a}$$

  
Past $2/a$ the vertical step overshoots the valley floor by more than it started from, so each step lands farther away than the last and the path blows up. You can see this by pressing Too large.






  
3. Picking the learning rate

  

    
Too small
crawls
Always safe but slow. The path inches along the shallow direction and takes thousands of steps.

    
About right
converges
The steep direction settles fast and the shallow one follows. Some zigzag is normal.

    
Too large
diverges
Each step overshoots. The loss grows instead of shrinking, and the numbers soon overflow.

  

  
The valley is the real difficulty. The learning rate must be small enough for the steepest direction, yet that makes progress slow in the flattest one. The ratio between them is the condition number, here simply $a$. Raise $a$ in the lab and the good range of $\eta$ narrows.






  
4. Momentum

  
Momentum keeps a running velocity, like a ball rolling downhill. Each step adds the new gradient to a fraction $\beta$ of the old velocity:

  
$$v \leftarrow \beta\, v + \nabla L(\theta), \qquad \theta \leftarrow \theta - \eta\, v$$

  
Back-and-forth moves across the valley cancel out, while the steady push along the valley adds up. Set $\beta$ to 0.8 with the Good preset and compare the path. For this loss the stable range grows to $\eta < 2(1+\beta)/a$, but high momentum can also overshoot and swing around the minimum.






  
5. Three ways to compute the gradient

  
In machine learning the loss is an average over $n$ training examples, $L = \frac{1}{n}\sum_i \ell_i$. The three common variants differ in how many examples they use for one step.

  

  

    
VariantExamples per stepBehavior

    
      
BatchAll $n$Exact gradient, smooth path, but one step costs a full pass over the data.

      
Stochastic (SGD)1Very cheap and noisy. The noise can help escape shallow traps.

      
Mini-batch32 to 512A balance, and the default for neural networks because it maps well to GPUs.

    
  

  






  
6. The same thing in code

  
function descend(grad, start, lr = 0.1, beta = 0, steps = 100) {
  let theta = [...start];
  let v = theta.map(() => 0);          // velocity for momentum
  for (let s = 0; s < steps; s++) {
    const g = grad(theta);              // slope of the loss here
    v = v.map((vi, i) => beta * vi + g[i]);
    theta = theta.map((ti, i) => ti - lr * v[i]);
  }
  return theta;
}

// the valley from Fig 1, with a = 5
descend(([x, y]) => [x, 5 * y], [-5, 2], 0.15);






  
7. Where it shows up

  
Gradient descent is the training engine behind Linear Regression on large data, Logistic Regression, which has no closed form, and every neural network. The Perceptron rule is a close cousin, since it also nudges weights against an error. It needs a gradient, so the loss must be differentiable. See Derivatives for the slope in one dimension. On a bumpy, non-convex loss it finds a local minimum, not always the best one. For the bigger picture, read Machine Learning Algorithm Groups.
