Q-learning and Dyna-Q

An agent learns by trying. It keeps a score for every action in every state, and nudges that score toward what it just saw.

A small grid. The agent starts at S, wants the green cell worth +1, and must avoid the red cell worth -1. Each step costs a little. It knows nothing at first. Run episodes and watch values spread backward from the goal and arrows appear. Then raise the planning steps to turn plain Q-learning into Dyna-Q and compare how few episodes it needs.

Readout

    

  






  
1. The setting

  
In reinforcement learning an agent in a state picks an action, gets a reward and lands in a new state. The goal is a policy that collects the most total reward. Nobody gives the right answers. The agent finds them by acting.






  
2. The Q table

  
$Q(s,a)$ estimates how much total future reward you get by taking action $a$ in state $s$, then acting well. If you know $Q$, the best policy is simply "pick the action with the highest $Q$".






  
3. The update

  
After each step $(s,a,r,s')$, move $Q(s,a)$ toward a better estimate, the reward plus the discounted best value of the next state:

  
$$Q(s,a)\leftarrow Q(s,a)+\alpha\Big[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\Big]$$

  
    
    
  • $\alpha$ is the learning rate, how far to move.
    • 
    
  • $\gamma$ discounts the future. Near 1 the agent plans far ahead.
    • 
    
  • The bracket is the temporal-difference error: how wrong the old guess was.
    • 
    
  • Because of the $\max$, it learns the best policy even while exploring. It is called off-policy.
    • 
  






  
4. Explore or exploit

  
If the agent always takes its best-known action it may never find better ones. Epsilon-greedy picks a random action with probability $\varepsilon$ and the best one otherwise. A common plan starts with a high $\varepsilon$ and lowers it over time.






  
5. Dyna-Q: learn from imagination

  
Q-learning throws away each real experience after one update. Dyna-Q also records it in a small model: "in state $s$, action $a$ gave reward $r$ and led to $s'$". After every real step it replays $n$ random remembered transitions as extra updates.

  
Real steps are expensive and imagined ones are free, so values spread across the grid much faster. Set Plan n to 20 and compare steps needed per episode. This is the simplest model-based method.






  
6. Limits

  
    
    
  • A table needs one entry per state. For huge or continuous states, replace it with a neural network, as in Deep Q-Network.
    • 
    
  • A learned model can be wrong. Planning on a wrong model reinforces mistakes. Dyna-Q assumes a fixed world.
    •
