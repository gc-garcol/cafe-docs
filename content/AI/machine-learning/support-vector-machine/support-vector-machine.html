Support Vector Machine

Do not just separate the classes. Separate them with the widest possible street, and let only the points on the curb decide where it goes.

Readout

    

  






  
1. The widest street

  
Many lines can separate two classes. The SVM picks the one with the largest margin, the gap to the nearest point on each side. A wide margin is less sensitive to small changes, which tends to generalize better.


Only the points on the margin matter. Delete all the others and the boundary stays put.






  
2. The math

  
Label classes $y_i\in\{-1,+1\}$. The boundary is $w^\top x+b=0$, and the margin width is $2/\|w\|$. Maximizing it means minimizing $\|w\|$ while keeping every point on its side:

  
$$\min_{w,b}\; \tfrac12\|w\|^2 \quad \text{s.t.}\quad y_i\,(w^\top x_i+b)\ge 1$$

  
Real data overlaps, so the soft margin lets points break the rule at a price. With slack $\xi_i\ge0$:

  
$$\min_{w,b}\; \tfrac12\|w\|^2 + C\sum_{i}\xi_i \quad\text{s.t.}\quad y_i\,(w^\top x_i+b)\ge 1-\xi_i$$

  
The same objective is the hinge loss $\max(0,\,1-y_i f(x_i))$ plus a penalty on $\|w\|$.






  
3. The knob C

  

    
$C$Effect

    
      
smallWide margin, many violations allowed. Simple model, may underfit.

      
largeNarrow margin, few violations. Fits the training data closely, may overfit.

    
  

  
Try the ring data with the extra feature off and a small $C$, then on.






  
4. Kernels

  
A straight boundary in a richer feature space can be curved in the original one. The ring is not separable by a line, but with the extra feature $x^2+y^2$ the inner class sits low and the outer class high, and a flat plane splits them.

  
The kernel trick gets this without computing the new features. The training only needs inner products, which a kernel supplies directly, such as the RBF kernel

  
$$K(x,x')=\exp\!\big(-\gamma\|x-x'\|^2\big)$$

  
RBF corresponds to infinitely many features. Its width $\gamma$ plays the role of a second knob, next to $C$.






  
5. Support Vector Regression

  
SVR turns the idea around. It fits a function and ignores any error smaller than $\varepsilon$, a tube around the line. Points inside the tube cost nothing. Only points on or outside it, the support vectors, shape the fit:

  
$$\min_{w,b}\; \tfrac12\|w\|^2 + C\sum_i \max\!\big(0,\;|y_i-f(x_i)|-\varepsilon\big)$$






  
6. Practical notes

  
    
    
  • Standardize features. Distance and margin depend on scale.
    • 
    
  • Training scales poorly beyond tens of thousands of rows. For large linear problems use a linear SVM or logistic regression.
    • 
    
  • Outputs are scores, not probabilities. Calibrate if you need probabilities.
    •
