Principal Component Analysis

Squash many features into a few without losing the story. PCA finds the direction along which the data varies the most, then keeps that direction and drops the rest.

1. Why drop dimensions

  
Real data often has many features that move together, such as height and weight, or neighboring pixels. The cloud is flat in practice, with a few directions that matter and many that are almost noise. PCA finds a new set of axes aligned with the cloud, ordered from most to least spread, so you can keep the first few. That gives faster models, less noise, and data you can plot in 2D.

  
Keep the directions where the data actually moves.






  
2. The goal

  
First subtract the mean from every feature so the cloud is centered at the origin. For a unit direction $u$, the shadow of a point $x_i$ is the number $u^\top x_i$. The variance of the shadows is

  
$$\operatorname{Var}(u) = \frac{1}{n}\sum_{i=1}^{n} (u^\top x_i)^2 = u^\top C\, u, \qquad C = \frac{1}{n}\sum_{i=1}^{n} x_i x_i^\top$$

  
$C$ is the covariance matrix. PCA looks for the unit vector $u$ that makes $u^\top C u$ as large as possible. That is Fig 2: the peak of the curve.

  
Maximizing the spread and minimizing the dropped distance are the same problem. By Pythagoras, each point satisfies $\lVert x_i\rVert^2 = (u^\top x_i)^2 + \text{distance}^2$, and the left side does not depend on $u$. So when the shadows grow, the leftover distance shrinks by exactly the same amount.






  
3. The answer is an eigenvector

  
The maximizer satisfies $C u = \lambda u$, so it is an eigenvector of $C$, and the variance it keeps is the eigenvalue $\lambda$. Sorting eigenvectors by eigenvalue gives the principal components. They are perpendicular to each other, and the fraction of variance kept by the first $m$ is

  
$$\text{explained} = \frac{\lambda_1 + \dots + \lambda_m}{\lambda_1 + \dots + \lambda_d}$$

  
For two features, $C = \begin{pmatrix} a & b \\ b & c \end{pmatrix}$ has $\lambda = \dfrac{a+c}{2} \pm \sqrt{\left(\dfrac{a-c}{2}\right)^2 + b^2}$, and the best angle is $\tfrac12 \operatorname{atan2}(2b,\, a-c)$. See Eigenvalues and Eigenvectors and Matrix Diagonalization for why this works.






  
4. Recipe

  
    
    
  1. Center the data, and usually scale each feature to unit variance.
    2. 
    
  2. Compute the covariance matrix $C$.
    3. 
    
  3. Find its eigenvectors and eigenvalues, and sort them from large to small.
    4. 
    
  4. Keep the top $m$ eigenvectors, enough to explain, say, 95% of the variance.
    5. 
    
  5. Project: the new coordinates are $z = U_m^\top x$.
    6. 
  

  
In practice libraries use the singular value decomposition instead of forming $C$, which is more accurate and faster for wide data.






  
5. The same thing in code

  
function pca2d(points) {
  const n = points.length;
  const mx = sum(points.map(p => p.x)) / n, my = sum(points.map(p => p.y)) / n;
  const c = points.map(p => ({ x: p.x - mx, y: p.y - my }));   // center

  const a = sum(c.map(p => p.x * p.x)) / n;                     // covariance
  const b = sum(c.map(p => p.x * p.y)) / n;
  const d = sum(c.map(p => p.y * p.y)) / n;

  const mid = (a + d) / 2, r = Math.hypot((a - d) / 2, b);
  const lambda1 = mid + r, lambda2 = mid - r;                  // eigenvalues
  const theta = 0.5 * Math.atan2(2 * b, a - d);               // first component
  return { theta, lambda1, lambda2, explained: lambda1 / (lambda1 + lambda2) };
}






  
6. Limits

  
    
    
  • Linear only. PCA finds straight directions. A curled cloud, like a spiral, needs a nonlinear method such as t-SNE or an autoencoder.
    • 
    
  • Variance is not importance. A direction with large spread may be useless for predicting your label, and a small one may be the key.
    • 
    
  • Scale matters. Without standardizing, the feature with the largest units dominates the first component.
    • 
    
  • Components are blends. Each new axis mixes the original features, so it can be hard to name.
    • 
  

  
PCA is often the first step before K-means or k-NN, which both suffer when there are too many dimensions. See the map in Machine Learning Algorithm Groups.
