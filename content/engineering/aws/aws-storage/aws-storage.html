1. S3

  
Simple Storage Service stores objects in buckets, addressed by key. It is designed for 11 nines of durability, with data kept across at least three zones. Reads after writes are strongly consistent. Pick a storage class by access pattern and move data between them with lifecycle rules.

  

    
ClassUse

    
      
StandardFrequent access.

      
Intelligent-TieringUnknown or changing access. It moves objects for you.

Block public access by default, turn on versioning for recovery, and use presigned URLs to share a single object.







  
2. EBS

  
Elastic Block Store volumes are disks for EC2. A volume lives in one zone and attaches to an instance in it. Types: gp3 general purpose, io2 for high IOPS, st1 and sc1 for throughput and cold data. Snapshots are incremental and stored in S3, and can be copied across Regions.







  
3. EFS

  
Elastic File System is managed NFS. Many instances, containers and Lambda functions can mount it at once, across zones, and capacity is elastic. It is for Linux. Throughput modes and storage classes trade cost against speed.







  
4. FSx

  
Managed third-party file systems. FSx for Windows gives SMB shares with Active Directory. FSx for Lustre is a parallel file system for HPC and machine learning, and links to S3. FSx for NetApp ONTAP and OpenZFS bring those features and protocols.
