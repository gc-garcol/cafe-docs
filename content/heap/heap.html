Heap

A complete binary tree stored in a plain array, where every parent is no larger than its children. The smallest item is always at the top, and insert and remove cost O(log n).

1. The idea

  
A heap keeps just enough order to find the minimum fast. It does not sort everything. It only promises one rule, the heap property: every parent is less than or equal to its children. Siblings have no order between them.

  
The shape rule keeps the tree complete: every level is full except possibly the last, which fills from the left. That shape lets you store the tree in an array with no pointers.

  
parent(i) = floor((i - 1) / 2)
left(i)   = 2i + 1
right(i)  = 2i + 2

  
The root is the minimum. Everything else only has to stay below its parent.






  
2. Insert: sift up

  
Put the new value in the first free slot at the end of the array, which keeps the tree complete. It may now be smaller than its parent, so swap upward until the parent is no larger.

  
function push(h, x) {
  h.push(x);
  let i = h.length - 1;
  while (i > 0) {
    const p = (i - 1) >> 1;
    if (h[p] <= h[i]) break;
    [h[p], h[i]] = [h[i], h[p]];
    i = p;
  }
}

  
The path from a leaf to the root has about log₂ n nodes, so at most that many swaps happen.






  
3. Extract min: sift down

  
The answer is h[0]. To remove it without leaving a hole, move the last item to the root, then swap it downward with its smaller child until both children are no smaller than it.

  
function pop(h) {
  const top = h[0], last = h.pop();
  if (h.length === 0) return top;
  h[0] = last;
  let i = 0;
  for (;;) {
    let m = i, l = 2 * i + 1, r = l + 1;
    if (l < h.length && h[l] < h[m]) m = l;
    if (r < h.length && h[r] < h[m]) m = r;
    if (m === i) break;
    [h[m], h[i]] = [h[i], h[m]];
    i = m;
  }
  return top;
}

  
Pick the smaller child, not either child. Otherwise a larger child could end up above a smaller one and break the heap property.






  
4. Build a heap in O(n)

  
Inserting n items one by one costs O(n log n). Heapify does better. Copy the items into an array, then sift down every non-leaf node from the last one back to the root.

  
for (let i = (n >> 1) - 1; i >= 0; i--) siftDown(h, i);

  
Most nodes sit near the bottom and move very little, so the total work sums to O(n). Heapsort uses this: heapify, then pop the minimum n times.

6. Where it shows up

  
    
    
  • Priority queues in schedulers and event simulations.
    • 
    
  • Dijkstra and Prim pick the next closest node with a min-heap.
    • 
    
  • Top-k: keep a min-heap of size k to track the k largest items in a stream.
    • 
    
  • Merging k sorted lists: the heap holds one head per list.
    • 
    
  • Heapsort: in place, O(n log n), not stable.
    •
