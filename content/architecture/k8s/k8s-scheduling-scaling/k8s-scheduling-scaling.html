1. Requests / Limits

  

    
FieldEffect

    
      
requestsReserved on the node for scheduling.

      
limitsThe ceiling. CPU over the limit is throttled. Memory over the limit gets the container killed (OOMKilled).

    
  
  
Set requests close to real use. Too low and nodes overcommit. Too high and capacity is wasted.

3. Affinity / Anti-Affinity

  
nodeAffinity attracts a Pod to nodes by label, as a hard required rule or a soft preferred one. podAffinity places Pods near others, for example with a cache. podAntiAffinity spreads them, for example one replica per zone. topologySpreadConstraints spread more evenly.







  
4. Taints / Tolerations

  
A taint on a node repels Pods. A toleration on a Pod lets it in. Effects are NoSchedule, PreferNoSchedule and NoExecute, which also evicts running Pods. A toleration only permits placement. To force it, add affinity too.







  
5. Probes

  
    
    
  • Startup: waits for slow starts. Other probes are held until it passes.
    • 
    
  • Readiness: failing removes the Pod from Service endpoints. The container is not restarted.
    • 
    
  • Liveness: failing restarts the container. Use it only for deadlocks, never for dependency checks.
    • 
  






  
6. HPA / VPA

  
The Horizontal Pod Autoscaler changes replica count. Each cycle it multiplies the current replicas by the ratio of the observed metric to the target and rounds up. It needs metrics-server for CPU and memory, and has a stabilization window to avoid flapping.

  
The Vertical Pod Autoscaler adjusts requests and limits. Do not drive HPA and VPA from the same metric.







  
7. KEDA

  
Event-driven autoscaling. KEDA reads external signals such as queue length, Kafka lag or a Prometheus query, and feeds them to an HPA. It can scale a workload down to zero and back up when events arrive.







  
8. PDB

  
A PodDisruptionBudget limits how many Pods of an app may be down during voluntary disruptions such as a node drain or upgrade. Set minAvailable or maxUnavailable. It does not protect against crashes or node failure.
